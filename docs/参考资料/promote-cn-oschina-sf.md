# 开源中国 / 思否版：本地优先 AI 智能体工作台「朱峰社区智能体无限」开源发布

> 这两个平台偏"项目发布"风格，用软件资讯/项目介绍的口吻，客观陈述为主。

**朱峰社区智能体无限（Infinity）v5.1.0 现已开源**（MIT 协议），这是一个 Windows 本地优先的 AI 智能体工作台。

## 主要特性

**多智能体并发**
支持同时运行 400+ 个 AI 对话，每个对话是独立智能体，拥有独立的模型配置、工具集和上下文。智能体之间可以互相派活、互相监督、汇总结果，实现真正的多智能体协作。

**83 个内置工具**
分 4 大类（日常/编程/写作/画布），覆盖文件读写、代码执行、网页抓取、Git 操作、定时任务、文生图、视频生成等场景，开箱即用。

**无限画布节点图**
在可视化画布上创建智能体节点、连接依赖、运行流水线。每个节点是一个完整智能体，相当于每个格子都会自己干活的 DAG 工作流引擎。支持节点修复、固化、全局上下文共享。

**自我修复能力**
智能体执行出错后自动重新读代码、定位根因、打补丁并验证，而非直接报错退出。

**超长计划持久化**
跨对话的大型任务可持久化为计划文件（MD），新对话可无缝接续执行。

**零依赖部署**
服务端完全基于 Python 标准库实现（HTTP keep-alive、路由、数据库、任务调度均为手写），无 pip 依赖、无 Node、无 Docker，解压后双击即可运行。

**数据本地化**
所有数据（对话、API 密钥、数据库）均存储在本地，不经过任何第三方服务器。

## 技术架构

| 层 | 实现 |
|---|---|
| 后端 | Python 3.11+，纯标准库 HTTP server（keep-alive，多线程） |
| 前端 | 原生 JS，模块化加载，无限画布渲染 |
| 内核 | 工具调用循环 + 自检 + 计划持久化 |
| 存储 | 本地 SQLite / kv_store |
