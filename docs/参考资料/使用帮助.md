## 一、软件概述

**朱峰社区智能体无限（Infinity）** 是一款本地运行的 AI 智能体工作台，以「无限画布」为核心，把多轮对话、工具调用、文生图、视频生成、任务管理全部铺在同一块画布上。核心特点：

- **真·自主执行**：AI 会把需求拆成步骤 → 逐步调用工具 → 主动验证 → 完成后汇报「✅ 任务完成」。
- **多对话并行**：可同时对多个对话框下达不同任务。
- **数据不出门**：全部本地运行，API Key 存于 `private/`，不外传。
- **开箱即用**：内置 Python 3.11 运行环境，解压即用。
- **自我保护**：健康守护 + 小狗守卫双防线，任务失败自动救、停滞主动干预。

## 二、启动与快速开始

1. 下载解压到本地任意目录（Windows 10/11 64 位，另提供 `Linux/start.sh` Linux 启动脚本与启动说明）。
2. 双击 `.启动朱峰社区智能体无限.bat`（无需安装 Python）。
3. 按界面提示配置模型 / API，开聊。

> 首次运行请确保程序目录有读写权限。版本号见 `private/version.json`。

## 三、无限画布工作台

### 3.1 画布基础操作
- **自由拖拽 / 缩放**：画布可平移缩放（`app-canvas.js`）。
- **双击创建**：双击画布空白处打开创建面板，新建对话框 / 图片 / 视频 / 提示词面板等节点。
- **右键快速创建**：画布空白处右键呼出「快速创建条」（带发送 / 语音输入），沿用上次全部设置直接开新对话。
- **Tab 快速创建**：随手按 Tab 弹出极简创建条，一步开新对话并发送。
- **小地图导航**（`app-minimap.js`）：右下角缩略图，快速定位大片画布。
- **Undo 撤销**（`app-undo.js`）：画布操作可撤销 / 恢复（含对话框历史恢复）。
- **背景特效**（`background.js`、`space-meteors.js`）：画布背景特效（如流星），设置可持久化独立存储。
- **点击特效**（服务端 `click_effect.py`）：鼠标点击反馈效果。

### 3.2 风筝（Kite）节点系统
- **风筝节点与连线**（`app-kite-core/links/nodes/panels.js`）：画布上以风筝形式展示节点，节点间连线（含端口连线 `app-kiteportlink.js`）。
- **风筝视觉**（`app-kite-vision.js`）：视觉能力接入。
- **风筝语音对话**：点击风筝龙头（单击，非拖拽）弹出专属语音聊天窗（`kite-voice-chat.js`），纯语音一对一：你说它听 → AI 答完自动接着听，像打电话一样。
- **风筝龙头拖拽**：拖动可调整锚点，与语音面板互不干扰。

### 3.3 媒体节点
- **图片节点 / 查看器**（`app-imagenode.js`、`app-imageviewer.js`、`image-node.js`）：画布上查看放大图片。
- **媒体拖拽**（`app-mediadrag.js`）：媒体文件拖入画布。
- **媒体节点**（`app-medianode-x.js`）：视频等媒体节点。
- **通道面板**（`panel-image-channels.js`）：图片通道管理。

## 四、对话框与聊天系统

- **多对话框管理**（`app-chatmgr.js`、`app-chatbox-projects.js`）：多个对话节点同时挂画布，各自独立任务。
- **聊天交互**（`chatbox-03-chat-interaction.js`）：发送、流式回复渲染（Markdown + 代码高亮 + Mermaid 图表），全异步不卡顿。
- **模型选择器**（`chatbox-01-model-selector.js`）：每个对话可单独选模型。
- **发送状态**（`agent-00-send-status.js`）：发送中 / 完成状态显示；中途停止的对话也能正常继续发送。
- **成功箭头与任务结果直达**（`chatbox-02-success-arrow.js`）：完成后显示「查看成功 N」「查看验证结果」按钮，点一下镜头自动跳到答案画布。
- **消息净化**（`agent-02b/02c`）：自动清理假工具标签等异常输出。
- **粘贴卡片化**（`feature-输入框粘贴卡片化`）：大段粘贴（>80 字或含换行）自动变成可删除的小卡片，AI 能区分「打的字」和「粘贴的内容」。
- **Ask User 提问**（`agent-04-ask-user.js`）：AI 可向用户提问（单行 / 表单模式），暂停等待回答。
- **任务清单面板**（`app-taskpanel.js`）：AI 执行时的任务清单实时展示进度。
- **Toast 提示**（`chatbox-00-toast.js`、`toast-stack.js`）：全局轻提示。

## 五、Agent 执行引擎（三模式）

每个对话可选择执行模式（`agent-02-loop-core.js` 循环核心 + 模式选择）：

| 模式 | 说明 |
|---|---|
| 直接聊天 | 纯对话，不调用工具 |
| 工具循环 | AI 可调用工具后再回答 |
| 自主循环 | 全自主：拆步骤→执行→验证→汇报，直到任务完成 |

配套能力：
- **工具结果管理**（`agent-03-tool-results.js`）：结果卡片渲染、超长结果存档与查回。
- **推理等级**（`reasoning-levels.js`）：模型思考深度可调。
- **项目记忆**（`agent-01-project-memory.js`）：对话自动记录工作记忆，跨轮召回。
- **错误处理**（`agent-errors.js`）：出错重试与提示。
- **对话模式记忆**：当前选中的模式即默认模式，下次沿用。

## 十五、扩展生态

## 二十三、常见问题 FAQ

**Q：怎么开始用？**
解压 → 双击启动 bat → 配置模型 API → 双击画布空白处（或右键 / Tab）创建第一个对话。

**Q：点发送特别卡？**
老版本的同步请求阻塞已彻底修复，Ctrl+F5 强刷浏览器即可。

**Q：大任务做不完怎么办？**
直接交给它，会自动建「超长计划」分批执行；关掉软件明天新对话可无缝续做。

**Q：对话卡死了？**
小狗守卫会自动救（停滞超时会暂停并注入修改方法继续）；也可查看「守护账本」了解它做了什么。

**Q：怎么迁移到新电脑？**
用「设置导出 / 导入」；隐私区可控，API Key 不会被导出，需要单独配置。

**Q：AI 会乱删我的文件吗？**
删除、改系统配置等高风险操作需你确认；且文件修改自动留 .bak 备份，画布操作支持 Undo。

**Q：制作新版本时有什么必须做的？**
⚠️ 必须先读取隐私区检查清单 `private/用户设置/release_checklist.json` 并逐项执行，重点包括：
1. **清空文件树钉住的项目（ft_pins）**——钉住项属于个人使用状态，发布前必须置空（user_settings.json 中键 `ft_pins` 置 `[]`），不能把开发机的路径带到新版本里；
2. 清理隐私区个人数据（api_keys.json 置空、删除 db/、server.pid、worklog.json、backups/）；
3. 确认 version.json 与 port.json 的版本号和端口已更新。
