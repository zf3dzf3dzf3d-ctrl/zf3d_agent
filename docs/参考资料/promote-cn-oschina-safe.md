**朱峰社区智能体（Infinity）v5.1.0 现已开源**（MIT 协议），这是一个 Windows 本地优先的 AI 智能体工作台，所有数据保存在用户本地。

## 主要特性

**多智能体并发**
支持同时运行 400+ 个 AI 对话，每个对话是独立智能体，拥有独立的模型配置、工具集和上下文。智能体之间可以互相派活、汇总结果，实现多智能体协作。

**83 个内置工具**
分 4 大类（日常/编程/写作/画布），覆盖文件读写、代码运行、网页抓取、Git 操作、定时任务、文生图、视频生成等场景，开箱即用。

**可视化画布节点图**
在画布上创建智能体节点、连接依赖、运行流水线。每个节点是一个完整智能体，相当于一个可视化的 DAG 工作流引擎。支持节点固化、全局上下文共享。

**自动错误恢复**
智能体执行出错后会重新读取代码、定位问题原因、修改并验证，而不是直接报错退出，提高长任务的完成率。

**长任务计划持久化**
跨对话的大型任务可保存为计划文件（Markdown），新对话可以无缝接续执行。

**零依赖部署**
服务端完全基于 Python 标准库实现（HTTP keep-alive、路由、数据库、任务调度均为手写），无 pip 依赖、无 Node、无 Docker，解压后双击即可运行。

**数据本地化**
对话记录、API 密钥、数据库均存储在用户本地计算机中。

## 技术架构

| 层 | 实现 |
|---|---|
| 后端 | Python 3.11+，纯标准库 HTTP server（keep-alive，多线程） |
| 前端 | 原生 JS，模块化加载，画布渲染 |
| 内核 | 工具调用循环 + 自检 + 计划持久化 |
| 存储 | 本地 SQLite / kv_store |
