# 远程控制功能 · 帮助与介绍

## 这是什么

朱峰社区智能体无限 5.1.0 内置的跨主机远程协助系统：把本实例部署到公网服务器后，任意两台装了本系统的电脑可以安全地互相远程操作——控制端能看到被控端一模一样的"影子界面"，像坐在对方电脑前一样操作。

## 核心特性

1. **加密唯一 ID**：每台实例首次启动本地生成 32 字节主密钥（永不出本机，存 `private/remote_id.json`），对外只暴露其哈希短码——单向不可逆，泄露也无法伪造身份。
2. **盲配对**：服务器不提供任何在线设备列表，任何人都无法浏览/发现/枚举其他主机。两端在服务器上互为匿名影子，防止误接触。
3. **30 秒一次性配对码（暗号）**：被控端主动生成 6 位配对码，30 秒有效、用一次即焚；生成新码自动作废旧码。
4. **双向比对码防中间人**：invite / accepted 握手时双端同显 4 位比对码，电话/口头核对一致才继续。
5. **时效授权**：被控端点「同意」时选有效期（1 小时 / 8 小时 / 1 天 / 7 天 / 自定义，上限 30 天），**没有永久选项**，到期自动销毁会话。
6. **端到端加密中转**：控制指令与界面数据全程加密，服务器只做盲转，看不到明文。
7. **多机管理**：控制端可同时挂多台被控机，面板列表显示每台短 ID + 剩余授权时长，一键切换。
8. **常驻横幅**：被控期间界面顶部横幅显示"正在被远程控制 · 剩余时间 + 立即断开"，本机操作优先，绝不无声被控。

## 怎么用（三步）

1. **部署中心**：把 5.1.0 整体部署到你的公网服务器，WebSocket 信令服务监听 8515 端口（纯 Python 标准库，无额外依赖）。
2. **打开入口**：点击任意聊天对话框顶栏的 🔗 按钮（提示文字「远程控制：本机 ID / 被控 / 控制他人」），右侧滑出全局唯一的「远程控制」面板。每个对话框顶栏都有这个按钮（🌌 星图 | 🔗 远程 | 🔧 工具 | 📜 日志 | ✕ 关闭），打开的都是同一个面板；面板也可以用 `App.openRemotePanel()` / `App.closeRemotePanel()` 代码调用。注意：远程控制的是整个应用界面，与具体某个对话无关。
3. **被控端**：在「远程」面板点「生成配对码」→ 30 秒内通过任意渠道（电话/微信）把 6 位码口头告诉对方。
4. **控制端**：「远程」面板输入配对码发起邀请 → 双方核对 4 位比对码 → 被控端弹窗点「同意」并选择时长 → 开始远程，影子界面实时同步。

断开方式：被控端点横幅上的「立即断开」，或控制端点「结束会话」；到期自动断。

## 安全防线（六层）

| 层 | 机制 |
|---|---|
| 1 | 盲配对——无设备列表可探测 |
| 2 | 30 秒一次性配对码，新码作废旧码 |
| 3 | 错误熔断——输错 3 次冻结 10 分钟（try-later） |
| 4 | 被控端弹窗明确同意 + 双方比对码核对 |
| 5 | 时效授权（最短 1 小时，最长 30 天，无永久） |
| 6 | 端到端加密中转 + 高频熔断（1 秒 50+ 异常事件即断开） |

另含：服务器匿名化日志（只记哈希与时间戳）、50 并发上限、版本兼容检查、断线降级（10 秒标灰/60 秒挂起/DOM 差量续传）、本地操作审计日志（存 private/，不上传）。

## 常见问题

- **配对码过期了？** 重新生成即可，旧码已自动作废。
- **提示 try-later？** 配对码输错 3 次，10 分钟后再试。
- **对方一直没收到邀请？** 确认双方都连上了同一台中心服务器，且被控端 30 秒内未重新生成新码。
- **改了服务器代码不生效？** 重启 5.1.0 服务进程；浏览器 Ctrl+F5 强刷。
