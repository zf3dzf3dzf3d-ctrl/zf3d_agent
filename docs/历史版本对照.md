## 二、各阶段详细说明

### 5.5.0（当前版本）—— 桌面客户端与跨平台
- **独立桌面客户端**：托盘常驻，「打开主界面」打开 pywebview 原生窗口（WebView2 内核，Win10/11 零依赖），关窗口不影响后台服务，单实例复用窗口，品牌图标。
- **跨平台启动**：新增 start.sh 与 platform_compat 兼容层，Linux/macOS 可启动（解释器自动探测 .venv/自带 Python/系统 Python）。
- **大师集群**：对话框右上角大师入口统一收敛到大师集群菜单，移除各大师独立注入图标。
- **稳定性修复**：ai_accounts 余额设置改为动态探测表列，错误不再静默吞噬；token_logs 流水写入失败不影响到账响应。

### 5.4.5 —— 多角色协作与全面工具化
- **多角色协作与质检**：策划拆解 → 执行 → 质检验收流水线，一键返回重来、轮次可见，大幅提高任务成功率，无需人工反复校验。
- **多策划 / 多审核 / 多施工队**：每种角色均可开多个窗口并行工作——多份策划方案先整合对比再由用户裁决开工；施工队可多队分片同时施工；审核支持多轮多窗口复核，主窗口负责方案整合与任务派发。
- **多窗口池 + 赛道交通网络**：窗口池统一调度，任务像赛道车流通行，支持断点恢复。
- **风筝系统监控一切**：看门狗、FPS 守卫、网络守卫、索引守卫等多种「小狗守卫」，卡死自动拉回、故障自修复。
- **导航与整理**：一键整理画布、快速定位窗口。
- **长任务与长期记忆**：超长任务持久化计划跨对话接力，语义记忆记住项目背景。
- **全家桶工具**：内置浏览器、3D 引擎与 3D 生成、PPT 生成、图片工具工作台、TTS 语音、屏幕截图录制。
- 功能全景：无限画布多窗口 / 多角色流水线与工单系统（多策划·多施工队·多审核）/ 窗口池与计划分批 / 风筝监控 / AI 工具全家桶 / 技能与扩展市场 / 模型多渠道与备份恢复。

### 5.3.0 / 5.3.5（2026-09）—— 发布工程沉淀
- 延续 5.2.5 核心架构：对话池、闸门 v4、蜂群并发、小狗守卫、热更新。
- 对话与调度稳定性核心持续打磨，目录级版本快照保证发布可回溯。
- 核心能力：7 种 Agent 引擎、主脑与记忆（SQLite + embedding + RAG + git 自校验）、六大工具体系、MCP 客户端网关、技能包、对话模式插件。

### 5.2.5（2026-09）—— 每对话个性化与可视化
核心理念：把控制权下放到每一个对话。
- **基于对话的工具抽屉**：每个对话独立工具抽屉，写作对话挂写作工具、编程对话挂编程工具。
- **基于对话的工具配置**：单个工具的参数和权限按对话细调。
- **基于对话的循环和上下文配置**：7 种引擎随选 + 独立上下文压缩策略。
- **新版主界面 + 风筝统计系统**：token 用量、模型调用、车道调度状态实时可视化。

### 5.2.0（2026-09）—— 对话池与后勤线重造
- **对话池 chat_pool（本版本最大升级）**：请求所有权移交服务器槽位，断网/刷新不掉字、断点续读，杜绝重试风暴。
- **连接池**：按域名分组 HTTPS 长连接复用，每请求省 50~200ms 握手。
- **前缀缓存观测**：解析 cached_tokens，缓存命中率与省钱额可见。
- **小狗守卫 v5.2**：工具停滞检测（默认 30 分钟）、忙时免打扰、日志轮转。
- **热更新引擎**：服务端模块热重载，前端变更自动通知刷新。

### 5.1.5（2026-09）—— 主脑与做梦
- **主脑系统**：AI 自动观察项目运行并节流总结播报，底栏「🧠主脑」常驻面板，重启后历史可回放。
- **做梦系统**：「🌙做梦」开一个无目标「梦境」，AI 自由联想自言自语，梦境手记落盘，多梦并行。
- **对话交通系统 chat_gate v4**：所有大模型请求经唯一闸门——按接口域名分车道组 + AIMD 自适应调度 + 车道数自适应伸缩。

### 5.1.2（2026-09）—— 手机控制与体系化文档
- **手机控制电脑**：手机浏览器访问电脑端同款界面（移动自适应 + token 认证）。
- **模型测速**：自动探测模型响应延迟，慢模型自动降权。
- 首次形成「六大部分」完整帮助文档框架与中英双语软件介绍，README 六部分结构自此定型。
- 多智能体协作（数百对话并行、派工协议、风筝监控）、六大底层引擎、识图与视觉工具集、文档格式转换。

### 5.1.0（2026-09）—— 多智能体协作与远程控制
- **跨主机远程控制**：盲配对 + 端到端加密 + 影子界面。
- **知识图谱系统**：实体-关系抽取 + 可视化 + AI 问答。
- **派小弟协议 v1.1**：派发/监控/回收/验证四段流水线 + 三关验收。
- **目标链统一协议**：唯一目标源是人类，全链可追溯。
- **画布流水线**：Mermaid 流程图部署成真实执行的对话节点。
- **文件变更溯源** + **FlowGlam** 炫酷流程图渲染。

### 5.0.6 ~ 5.0.8（2026-08~09）—— 画布体验打磨
- **发散收敛多视角对话**：一句话派出一队 AI（工程师/美工/程序员等视角），画布连线实时动画，一键收敛汇总。
- 画布流水线雏形开发。
- **模型配置管家**：对话式增删改模型配置、联网查上游模型列表。
- 任务结果直达按钮、文件浏览分页提速、508 乱码等一批稳定性修复。

### 5.0.5（2026-08末）—— 守护与计划
- **超长计划系统 Long Plan**：50~100+ 步超长任务持久化为 Markdown 计划，分批认领执行、跨对话接力。
- **小狗守卫 · 守护账本**：失败自动救、停滞 10 分钟干预、空闲巡逻，动作全部记账可查。
- **急救箱恢复内核**：自检、对话式修复、一键还原核心快照。
- **健康守护 v2**：只计「人在」时间的久坐提醒与强制休息。
- 设置导出/导入、语音命令自动发送、朗读助手（Edge TTS）、粘贴卡片化、撤销恢复对话历史。

### 5.0.1 ~ 5.0.4（2026-08）—— 无限画布成型

## 三、升级建议

- **1.0 ~ 4.x 用户**：核心体验已完全换代（画布 + 多智能体），建议直接升 5.5.0，旧版无可保留配置依赖。
- **5.0.x 用户**：风筝系统与守护体系已大幅增强，5.2.0 起网络稳定性发生质的飞跃（对话池），强烈建议升级。
- **5.1.x 用户**：5.2.0 的对话池/连接池直接解决断网丢字问题；5.2.5 的按对话配置显著提升多任务体验。
- **5.2.x / 5.3.x 用户**：5.5.0 在 5.4.5 多角色协作质检基础上新增桌面客户端与跨平台启动、窗口池与全家桶工具，升级成本低、收益明显。
