# 朱峰智能体无限  软件介绍

> 一个本地运行的 AI 多窗口工作台：把 AI 变成一支有分工、有监控、有记忆的团队，并通过多角色协作与历史沉淀持续改进任务质量。

## 一句话定位

在一张无限画布上开出任意多个独立 AI 窗口，每个窗口有自己的人设、模型、引擎和工具，协作完成从聊天、写代码到 3D/视频生产的全部工作。

## 30秒速览

- **这是什么**：本地运行的 AI 多窗口工作台，数据留在自己电脑上，不依赖云端
- **能干什么**：多个 AI 窗口分工协作，策划师拆解任务、施工队执行、审核员验收，自动完成复杂工程
- **适合谁**：同时跑多个 AI 任务的重度用户、做游戏/3D/内容生产的创作者、长期项目开发者
- **第一步**：打开面板 → 在画布上新建窗口 → 选模型和人设 → 开始对话

## 核心亮点

- 🖼️ **无限画布**：整个界面就是一张可无限平移缩放的画布，AI 窗口、浏览器、3D 引擎、视频、PPT 都是画布上的节点，节点间一键点击箭头即可流转任务
- 🪟 **多窗口独立设置**：每个窗口独立配置模型、角色人设、UI、引擎、工具集、Git 分支，组成你的 AI 团队
- 🎭 **策划师/审核员/施工队多角色流水线**：一键创建多角色协作（策划拆解 → 施工队执行 → 审核员验收），支持一键返回重来，轮次可见。多角色相互校验大幅提高任务成功率，无需人工反复核对，节省大量时间和 token
- 🛤️ **多窗口池 + 赛道交通网络**：窗口池统一调度，任务像赛道上的车流一样在窗口间通行，支持断点恢复
- 🪁 **风筝系统监控一切**：后台自动监控与自愈机制（风筝系统），配备小狗、风筝、主脑等多种「守卫」，卡死自动拉回、故障自动修复
- 🧭 **导航与整理**：一键整理画布、快速定位窗口，多窗口管理一目了然
- 🎯 **长任务与长期记忆**：超长任务持久化计划跨对话接力，语义记忆让 AI 记住项目背景
- 🧰 **全家桶工具**：内置浏览器、3D 引擎与 3D 生成、PPT 生成、图片工具工作台、TTS 语音、屏幕截图录制

## 功能全景

| 分类 | 能力 |
|---|---|
| 界面 | 无限画布、多窗口、节点连线、角色拖放、导航整理 |
| 协作 | 多角色流水线、蜂群调度、A/B 双解、考试式质检、工单系统 |
| 调度 | 窗口池、赛道交通网络、断点恢复、计划分批执行 |
| 监控 | 风筝监控、看门狗、FPS/网络/索引守卫、故障自修复 |
| AI 工具 | 文件/代码、git 快照、3D 生成、文生图/视频、TTS、浏览器自动化、屏幕截图录制、网络诊断 |
| 扩展 | 技能系统、扩展市场、MCP 接入、声明式 UI、自制模式 |
| 管理 | 模型多渠道、令牌统计、限流、备份恢复、在线升级、垃圾箱、分享、多语言 |

## 适合谁

- 需要同时跑多个 AI 任务的重度用户
- 想用 AI 做游戏/3D/美术内容生产的创作者
- 需要任务可监控、可回溯、可交接的团队
- 想本地部署、数据自主可控的开发者
- 需要管理多个复杂项目工程的程序员，以及长周期任务的开发者
- 需要批量自动化处理、多窗口并行跑复杂流程的开发者
