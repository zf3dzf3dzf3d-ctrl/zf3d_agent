## V2EX 正文（精简版，发 /go/create）

断断续续写了几个月，开源出来给大家看看：朱峰社区智能体无限（Infinity），Windows 本地优先的 AI 智能体工作台，MIT。

几个自认为有点意思的点：

1. 同时跑 400+ 个 AI 对话，每个对话是独立智能体，能互相派活互相监督
2. 83 个内置工具，文件/代码/Git/抓网页/定时任务/文生图都有
3. 无限画布节点图，连依赖跑流水线，每个节点都是个会自己干活的 AI
4. 出错会自己读代码定位打补丁，不是甩报错给你
5. 后端是纯 Python 标准库手写的 HTTP server，没有 pip 依赖，解压双击就跑

为什么死磕标准库：一个工具让用户先装 30 个依赖，90% 的人第二步就流失了。代价是 keep-alive 这种坑全得自己踩（比如请求体没排干被当下一个请求的请求行，501……）。
