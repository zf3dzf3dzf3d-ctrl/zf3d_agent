## 🚀 5.2.0 新增与升级（相对 5.1.5）

### 🏊 对话池系统（chat_pool）—— 本版本最大升级

以前一轮对话是「浏览器拖着请求跑」，Wi-Fi 瞬断一下，上游请求就被杀死，回复丢失、还会触发重试风暴整轮重发。5.2.0 改为**服务器内存池托管请求生命周期**：

| 层 | 内容 | 收益 |
|---|---|---|
| **A 缓冲区** | 请求所有权从浏览器移交服务器槽位，上游回复先落入槽位事件缓冲 | Wi-Fi 瞬断/刷新页面**不再丢回复**、不再重试风暴重发整轮 |
| **B 连接池** | 按 API 域名分组的 HTTPS 长连接复用 | 每请求省 TCP+TLS 握手 50~200ms，被供应商掐了自动重建 |
| **C 前缀缓存观测** | 服务端解析上游 usage 里的 cached_tokens | 缓存命中率/省钱额变成可见数字 |
| **D 会话池** | 对话→槽位持久映射 + 用量统计 | 多对话集中管理、刷新页面秒恢复 |

使用体验：断网重连后回复**从游标断点续读，一个字不丢**；停止按钮取消照常生效；闸门、小狗守卫、风筝系统零改动照常工作。

### 🚦 对话交通系统 chat_gate v4

所有大模型请求经唯一闸门调度：按接口域名分车道组 + AIMD 自适应调度 + 车道数自适应伸缩。多个对话并行时不互相踩踏，谁先走、走哪条道，闸门说了算。与对话池分工明确：**闸门=交警（谁先走），池=车队+仓库（用什么走、货在哪）**。

### 🐕 小狗守卫 v5.2：工具停滞检测

- 守卫升级：只有「真正在运行（闸门 state=running）但工具超过阈值（默认 30 分钟）无动静」的票据才触发提醒，且**自动去重**，不会反复打扰
- **忙时免打扰**：闸门有活跃票据（排队/运行）时不注入通知，避免插队打扰正常任务
- 崩溃报告保留到下轮巡检再投递，不丢失
- 日志自动轮转（上限 512KB），不会撑爆磁盘

### 🔥 热更新引擎（hot_reload）

服务端模块热重载：改代码不用重启整台服务器，模块全局状态（定时任务注册表等）跨重载保留；前端静态文件变更自动通知刷新。开发迭代速度大幅提升。

### 🪁 风筝系统性能优化

![风筝系统：有多少对话就有多少风筝](docs/images/5.2.0/风筝系统.jpg)

风筝节点渲染与位置管理专项优化，修复风筝位置丢失、风筝头样式问题，长画布多节点下更流畅。

### 🎆 交互细节修复

- **烟花/任务完成通知修复**：任务完成时庆祝烟花与通知必弹（双重兜底），不再偶发不出现
- **对话框最小化按钮补回**：标题栏最小化按钮回归
- 多处稳定性修复（乱码处理、run_code 引号转义、工具超时探测等）

## 定位对比（不变的核心优势）

![三重验证系统](docs/images/5.2.0/三重验证系统.jpg)

| 维度 | 传统智能体 | 朱峰智能体无限 |
|---|---|---|
| **对话框** | 一两个固定窗口 | 无限对话框 + 无限画布，数百对话并行 |
| **工具与内核** | 内置十来个工具 | 更多工具更多内核，六大引擎 + MCP/插件扩展 |
| **模型通道** | 全局一条通道 | 每条对话独立模型通道，互不干扰 |
| **运行可观测** | 黑盒执行 | 5.2.0 起连网络抖动都扛得住：池托管 + 闸门调度 + 守卫自动救 |
