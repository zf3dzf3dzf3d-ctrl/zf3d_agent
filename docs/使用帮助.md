## 一、快速开始

### 0. 30 秒速览 + 5 分钟上手

**这是什么**：本地运行的 AI 工作台，浏览器里开多个独立 AI 窗口，摆在一张无限画布上，可并行聊天、编程、生成 3D/图片/视频、操作浏览器。

**5 分钟上手路径**：
1. 双击根目录 `.启动朱峰智能体无限.bat`
2. 「设置 → 模型配置」填 API Key（或注册朱峰大模型直接用）
3. 试试画布：双击角色创建窗口,点击策划,弹出多个策划,点击完成后使用多个施工队进行工作,工作完成后,使用多个审核进行最终交付,最后让总结师进行总结.


### 1.1 这是什么

朱峰智能体无限是一个本地运行的 AI 工作台：浏览器里开出多个独立 AI 窗口，每个窗口是一个"角色员工"，可以聊天、写代码、生成 3D/图片/视频、操作浏览器、跑长任务。所有数据保存在你自己的电脑上。

### 1.2 启动

- **Windows**：双击根目录 `.启动朱峰智能体无限.bat`（首次使用先跑 `.安装依赖.bat`）
- **Linux / Mac**：进入 `Linux和Mac启动器` 目录按说明启动
- 启动后浏览器自动打开面板，默认地址 `http://127.0.0.1:端口因版本而异（5.5.0 为 8555，端口段约定见 docs/端口段约定.md）`

### 1.3 配置 API Key

进入「设置 → 模型配置」，填入你的模型服务 API Key（支持朱峰账户无key访问）。填好后回到聊天窗口发第一句话即可。

### 1.4 第一件事建议

新建一个窗口，让 AI 自我介绍，再用「模式」给它指定一个角色（如程序员、策划），体验角色分工。

## 二、核心功能：无限画布与多窗口


### 2.1 无限画布

- 面板就是一张可无限平移、缩放的画布，每个 AI 聊天窗口是画布上的一个节点
- 节点类型丰富：**AI 窗口节点、浏览器节点、3D 引擎节点、视频节点、演示（PPT）节点**等（对应 app-canvas-*-node 模块）
- 节点之间可以拉**箭头连线**（app-canvas-arrows），表示任务流转：比如"策划窗口 → 程序员窗口"交付需求
- **角色拖放**（role-drop）：把角色卡片直接拖到画布上即生成一个该角色的窗口

### 2.2 多窗口与窗口独立设置

每个窗口完全独立，互不干扰：

| 可独立设置 | 说明 |
|---|---|
| 模型 | 每个窗口可用不同模型/不同服务商 |
| 角色（人设/UI） | 每个窗口可绑定不同角色、系统提示词与窗口外观 |
| 工具集 | 每个窗口启用不同的工具分类：极简|编程|黑客|写作|DCC 等 |
| Git 分支 | 每个窗口可绑定独立代码分支，互不覆盖 |
| 团队人员 | 多窗口组成团队，任务在窗口间流转(策划师|质检员|多角色箭头方式协同工作) |

### 2.3 多窗口池与"赛道交通网络"

- 后台有**窗口池**（chat_pool / dispatch pool）统一调度，任务像车辆在赛道上一样在多个窗口间通行，避免单个窗口卡死拖累全局
- 池支持断点恢复（pool_resume）：服务重启后任务能接着跑

### 2.4 导航与整理

- 画布支持**导航/整理**功能：一键整理杂乱窗口、快速定位某个窗口，多窗口管理一目了然
- 窗口锁（canvas-node-modal-lock）撤销重做保存读取可防止误关正在干活的窗口

## 三、AI 能力工具箱

所有工具由 AI 自主调用，你只需用自然语言下指令。通过策划师和质检员的多轮对话,可以显著提高任务成功率。

### 3.1 文件与代码

- 读写文件、目录树、全局搜索、精确替换、移动文件（read_file / write_file / search_in_files 等）
- **前后保存git**：所有对话会在初始和结尾分别保存一个 git，保证工作永远不丢。
- **修改和删除**：修改文件之前必做备份，删除之前先移动到垃圾箱；超级大文件或者多文件删除必然先向用户提问。

### 3.2 3D 与美术

- **model_3d_gen**：文生 3D / 图生 3D（tripo、meshy、rodin、hunyuan 四家服务商），生成结果自动加载进内置 3D 工作台预览
- **zf3d 引擎节点**：画布上的 3D 引擎窗口（内置骨骼等工具为未来开发游戏打好基础,大模型驱动,超轻量）。

### 3.3 图片、视频、语音

- **image_gen** 文生图、**video_gen** 文生视频、**video_edit** 视频剪辑
- **TTS 语音合成**（tts_engine）：AI 朗读回复，支持流式输出
- **语音输入**（audio_recorder）：按住说话转文字

### 3.4 内置浏览器与自动化

- **browser_control**：AI 打开网页、点击、填表、截图、读正文、执行 JS，登录态跨重启保留
- 浏览器节点可直接钉在画布上当窗口用

### 3.5 屏幕与桌面

- **屏幕截图**（screenshot_capture / area_selector 区域选择）
- **屏幕录制**（screen_recorder，含转码）
- **键鼠控制**（set_camera / locate_mouse / control_keyboard）

### 3.6 其他

- **网页搜索 / 网络诊断**（net / net_ping / http_probe 等网络工具箱）
- **send_email** 发邮件
- **表格查看器 / pdf / word / PPT 技能**：内置 PPT 查看器，这是一套大模型直接操作的轻量生成能力，无需外挂二进制文件。

## 四、高级功能：多角色协作与风筝系统

### 4.1 策划师 / 质检员 / 施工队 / 总结师 / 多角色一键创建与一键返回

- 一键创建**多角色流水线**：策划师先拆解任务 → 执行者实施 → 质检员验收,一键多轮验证，大幅提高任务成功率和扩展性
- 对应模块：dispatch_swarm（蜂群调度）一个对话内部并发多子任务,可和主对话同时执行.不耽误开发时间.

### 4.2 施工队与 Git 赛马（多路开工/分工/回收）

- **多路开工**：结果增强按钮行点「施工队」→ 选数量 → 每队自动建一个**物理隔离施工场地**（git worktree，独立目录+独立分支 `site/race/<时间戳>_tN`），互不干扰可并行。
- **开工机制**：建场后自动开施工队角色窗，并把「开工派单消息」自动注入发送；若注入失败会弹 toast 提醒手动粘贴。源对话与施工队窗之间有橙色连线标识派单关系。
- **如何分工**：派单带计划 planId 时，施工队用 long_plan 读取计划 → plan_batch.claim 认领一批步骤执行，只做计划内步骤；多队并行即形成"赛马"，谁先做好用谁的。
- **如何回收**：各队成果落在各自分支上，比选后把优胜分支合并回 main，其余场地（worktree）可清理移除。清理前务必确认无未合并改动。

### 4.3 风筝系统（监控一切）

- **风筝查看系统** 观察每个对话,观察每条赛道,监控系统稳定性,窗口绘制情况,卡顿情况.
- **FPS 守卫**（mixin_fps_guard）：界面卡顿自动降载
- **网络守卫**（network_guard）：断网/代理异常自动重试
- **索引守卫**（index_guard）：主脑或小狗守卫等多种守卫方式，各管一摊，出问题自动拉起对话。

### 4.4 长任务与长期记忆

- **长任务 + 超长任务+长期目标**：超长任务落成持久化 MD 计划，跨对话接力执行，分批认领防上下文爆炸,超长任务模式所有工具结果全部保留,一字不丢.长期目标,可以设置跨对话的长期目标,可随时监控只要未完成就持续完成.
- **任务清单 task_list**：面板实时展示进度
- **长期记忆|工具记忆|项目记忆|内存记忆|目标总结记忆**适应短期中期长期任务,无感运行,一键记忆.
- **通信**：具有窗口通信监控调取工具结果的能力.

### 4.5 模式系统（modes/）

- 内置模式：对话引擎可以热插拔,可随时集成任何智能体引擎.设置工具和上下文循环内容.每个窗口都可以设置.
- 模式 = 角色设定 + 工具白名单 + 开场白，一键给窗口换"人格"不同角色分组还可以参与多角色对话能力.

## 五、扩展与设置

### 5.1 扩展系统（extensions/）

- **技能（skills）**：code_review 代码审查、docs_sync 文档同步、ppt_intro 等，市场一键安装
- **扩展市场（market.py）**：浏览/安装/更新社区扩展
- **MCP 接入（mcp.py）**：接入外部 MCP 服务器，扩充工具
- **声明式 UI（declarative_ui.py）**：扩展可自定义面板界面

### 5.2 设置中心

- **模型配置**：多模型多渠道，朱峰大模型登录即可连通,无需配置apikey,注册就送大量token.
- **令牌用量统计**（token_usage_stats）：花了多少 token 一目了然
- **主题与多语言**（i18n）：界面主题切换、多语言支持,支持中|繁|英|德|俄|日|韩|阿拉伯等11种语言.


## 六、常见问题 FAQ

**Q1：如何启动？**
双击启动朱峰智能体无限.bat即可无需安装.

**Q2：AI 回复报 API Key 错误？**
检查「设置 → 模型配置」中 Key 是否有效、点击验证看连通性,如果没有apikey可以注册朱峰会员,赠送token。

**Q3：TTS 没有声音？**
界面最上面有声音按钮打开即可。

**Q4：3D 模型生成失败？**
- 现象：调用 model_3d_gen 报错或无结果
- 原因：对应服务商（tripo/meshy/rodin/hunyuan）未配置 API Key，或选错了生成类型
- 步骤：进「设置」确认已配置对应服务商的 Key；确认对话工具分类包含 3D 能力；再试一次

**Q5：在线升级失败？**
- 现象：`.在线升级.bat` 报错或升级后异常
- 原因：权限不足或文件被占用
- 步骤：关闭所有窗口后以管理员身份运行；仍失败用「备份恢复」回到旧版本

**Q6：窗口卡死不动？**
- 现象：某个窗口长时间无响应
- 原因：多为网络中断或该任务卡住
- 步骤：关闭该窗口重启即可；网络不通时重新运行启动脚本，其余窗口不用关，任务可继续跑

**Q7：想彻底重置？**
- 现象：想恢复出厂状态
- 原因/步骤：备份 `data/` 和 `private/` 目录后删除，重启即全新状态。**注意：这是不可逆操作，务必先备份。**

**Q8：画布太乱找不到窗口？**
- 现象：窗口太多摆放杂乱
- 步骤：使用画布「整理」按钮一键排版，或用导航面板快速跳转定位。

**Q9：有哪些快捷键？**
画布与窗口常用操作（拖拽移动、滚轮缩放、框选多选、连线交付）在画布上直接操作；具体快捷键以后续版本面板内提示为准，暂无全局快捷键表。

**Q10：换电脑/迁移怎么办？**
- 步骤：拷贝整个项目目录到新电脑（重点保留 `data/` 与 `private/`），新电脑先跑 `.安装依赖.bat`，再启动即可，对话记录与记忆随目录走。

**Q11：多角色流水线怎么用？**
- 步骤：见第四节 4.1——一键创建多角色（策划师拆解 → 执行者实施 → 质检员验收），在窗口设置中把多个窗口组成团队并用箭头连线定义流转顺序即可。

**Q12：Token 用了多少/用完了？**
- 查用量：「设置 → 令牌用量统计」（token_usage_stats）一目了然
- 用完了：注册/充值朱峰大模型账号，或换成自己配置的其他渠道模型
