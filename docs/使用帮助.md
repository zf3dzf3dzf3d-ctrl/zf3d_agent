# 使用帮助

朱峰智能体无限是一套跑在你电脑上的智能体系统——本手册只管一件事：教你装好它、用熟它。

## 安装

1. 从朱峰社区下载安装包（一个 `.exe` 安装程序）。
2. 双击运行。若 Windows 弹出「已保护你的电脑」蓝色提示，点「更多信息」→「仍要运行」。
3. 按安装向导一路「下一步」：可以改安装目录（默认装在 Program Files），其他选项保持默认就行。
4. 装完从**开始菜单**启动。启动后自动打开本地页面，程序常驻在屏幕右下角托盘——关掉页面任务照样跑，托盘图标右键可以退出。
5. 第一次打开按提示填 API Key 就行——API Key 就是各家模型的「通行证」，去对应官网申请一个，复制粘贴进来即可；嫌麻烦可以直接开个对话说「帮我连通其他模型」，AI 管家带你配完。密钥只存本地、加密保存。

## 升级

- 软件检测到新版本会提示你：点更新，自动下载新版安装包并弹出安装程序，一路「下一步」装完即可——对话、配置、记忆全部保留。

## 快速上手

1. 从开始菜单启动 → 页面自动打开。
2. 配好至少一个模型的 API Key。
3. 在画布空白处右键 → 创建对话，挑个模型开工。
4. 把任务交代清楚（要什么、做成什么样），AI 自动拆解开干；想多线并行就多开几个对话。
5. 试试这几个好玩的：
   - 输入框粘一大段文字 → 自动变成卡片
   - 按 `Tab` → 一步开新对话直接发消息
   - 对 AI 说「把方案画成流程图部署到画布」→ 真流水线跑起来
   - 对 AI 说「派出一个团队做 xx」→ AI 组队干活
   - 点 Dock 栏的 i 小镇 → 看你的 AI 村民自己生活干活
   - 点 Dock 栏的 i 密室 → AI 现场给你造迷宫，闯关逃出去

## 三种工作姿势

- **无限画布**：主工作台，几十个窗口同屏跑，多线开工互不打扰
- **专注模式**：一次只盯一个对话，左侧列表随时切换，子对话也能看（Dock 栏可进）
- **缩小整理模式**：窗口多到眼花时一键切过去，所有对话缩成小卡片铺满一屏，像看地图一样整理

## 无限画布

基本手势：
- **挪画面**：按住鼠标中键拖
- **放大缩小**：滚轮
- **双击空白**：弹出创建面板（对话/图片/视频等）
- **右键空白**：快速创建条，按上次的设置直接再开一个对话
- **Tab 键**：一步开新对话并发消息
- **小地图**：右下角缩略图，画布大了靠它找路
- **框选批量**：空白处按下左键拉个框，圈中的窗口可以批量加审核、加策划、批量关闭
- **指挥台**：按键盘左上角的 `` ` `` 键唤起（Esc 关闭），宏命令和内部工作台都在这（进阶）
- **后悔药**：Ctrl+Z 撤销、Ctrl+Y 重做；图片还能点底部历史缩略图条切回任何一张
- **桌面小装饰**：顶栏有时间、农历节日、天气动画；画布标题可以钉在屏幕左边；背景能开轮播和流星特效

画布上能摆什么：

| 东西 | 干嘛用的 |
|---|---|
| 对话框 | 一个 AI 员工，核心单位 |
| 图片面板 | AI 画图和看图 |
| 视频面板 | AI 生成视频 |
| 提示词面板 | 管理和生成提示词（给 AI 的咒语） |
| 风筝节点 | 对话之间派活连线 |
| 流程图 | 流程图 / 部署成真流水线 |
| 演示节点 | 播放 AI 做的幻灯片 |
| 内置浏览器 | AI 像人一样操作网页：打开、点击、填表、截图 |

任务簿：画布上的便签不只是备忘——对 AI 说「把这个记到任务本上」，它干完会推给你验收：
- 三处联动：画布便签、AI 的任务清单、任务簿同步显示进度
- 顺口记日期：「9 月 10 号提醒我交房租」→ 自动变成日历提醒，到期弹窗+系统通知双提醒
- 过期任务自动置顶标红，当天到期高亮

## 缩小整理模式：几千个窗口一屏管住

- 画布一键切到「缩小总览」：所有对话框缩成小卡片铺满全屏，像看地图
- 整理模式里也能直接发消息、看每个对话的状态；双击空白直接建新对话
- 拖拽完全跟手；拖分组时子窗口跟着一起挪，松手才落位不回弹
- 分组可折叠，点组眼睛整组隐藏/显示；悬停卡片浮出完整标题
- 节点上千也很流畅；整理完退出，原画布位置全保留

## 对话框
- **派出协作师(未来主力工作内容)**：新建一个对话框,点击派出团队,选择协作师,然后输入一句话然后派出即可,随时和任何一个协作师插话,他们都会完成你的任务,然后让他们互相聊天,互相通气,随时插话,随时改进,他们也会自己审核,自己互相帮助 
- **每个对话独立选模型**：A 用 DeepSeek、B 用 Kimi，互不干扰
- **干活模式**：极简/编程/写作等，按对话切换（见下文「AI 怎么干活」）
- **排队机制**：AI 干活时你再发消息会自动排队，可编辑可撤回
- **粘贴自动变卡片**：粘一大段文字自动变卡片，AI 分得清你打的字和粘的内容
- **过程可折叠**：AI 干活的过程能收起来，界面清爽
- **回复好看**：代码高亮、图表渲染、选项可点
- **自动起名**：对话按内容自动命名
- **派出按钮**：对话框上一点，直达组队面板
- **里程碑四球**：对话框顶部的四颗进度球——策划球、进度球、审核球、总结球；进度球是朱峰首创，随时能报任务完成百分比，显示 85% 就是还没干完，接着推
- **专注模式**：一次只想盯一个对话？一键放大居中，左侧列表切换，干活不被打扰
- **老对话秒开**：历史消息懒加载，先显示最近 100 条，往上翻自动补载

## 注意力箭头：多团队不用满屏找窗口

- 多团队同时开工时，不用满画布找对话：一键返回、查进度、查分数、看总结，全收进一个提示面板
- 子对话干完活，右下角自动排队等你验收，点卡片直达
- 管得住几十个窗口，才能一边看电影一边干活

## 项目工作台

项目工作台是每个项目的指挥室：
- **团队页**：看队员、分组、派人，AI 自动写员工档案
- **数据页**：重要数据钉成卡片，AI 额度余额一目了然

## 派出团队

像游戏组队一样派人：
- 对话框上的派出按钮 → 打开卡通小队面板
- 点一下加人、右键撤人；面板记得住你上次摆哪了
- 派完自动收起；派单时能附一句叮嘱

举个例子：想做一个官网，就在对话框说「派出一个团队做一个官网」→ 确认窗里看看派了谁、不满意就换 → 派出去后画布上箭头实时动起来 → 全员交工有人拍板收货，你只管最后验收。

大活儿走专家团「4派2收」：
1. 派出前先弹确认窗：给你看这次派谁，不满意可以换
2. 策划师出方案 → 施工队动工 → 优化师+安全师同时把关（4 派）
3. 反驳师专门挑刺 → 裁决拍板收货（2 收）——活干没干好，不是 AI 自己说了算
4. 画布上箭头实时显示进度，所有人交完工才收口，不会提前散伙

新上岗的角色：

| 角色 | 干嘛的 |
|---|---|
| 验证师 | 拿多个程序交叉实测，不合格一票否决 |
| 反驳师 | 独立窗口专门挑刺 |
| 进化师 | 记录改进课题，让团队越干越强 |
| 优化师 / 安全师 | 精修文字 / 安全检查 |
| UI 设计师 | 界面类任务的专家 |

## 员工档案与团队分组

- 派出去的 AI 一键转正入职 → 自动生成员工档案
- 团队按项目分组管理
- 员工经验跨对话积累——干过的活都记得，越用越顺手

## 风筝系统

- 主对话把任务分给其他对话（像放风筝派活），自动盯进度、收结果，画布上用风筝+连线表示
- 点风筝龙头直接语音通话，像打电话一样聊
- 和派出团队怎么选？日常小活用风筝随手派，正式大活用派出团

## AI 怎么干活（工具分类）

每个对话可选不同的干活模式，AI 手里的家伙不一样：

- **极简模式**：读文件、写文件、跑命令、查资料——最常用的底子
- **编程模式**：加码数据库查询、记忆缓存、定时任务、代码辅助、AI 画图视频等
- **写作模式**：加码 40 个文字工具——润色、改写、摘要、检测敏感、多角色评审等

## 手机遥控（可选）

手机遥控不在电脑安装包里，需要时单独获取手机端「峰控」App（朱峰社区下载），或在手机/另一台电脑的浏览器打开社区网页遥控页（agent_remote.asp）：

1. 在软件里生成配对码（形如 ZFA-XXXXX-XXXXX，30 秒内有效、用一次就作废）；
2. 手机端输入配对码 → 出现电脑的影子界面，随手派活、看进度、收结果，人不在电脑前任务照跑；
3. 不在同一 Wi-Fi 也不怕：指令和消息走云端中继，手机上的新消息回电脑点对话框标题栏「⬇ 同步」一键拉回；
4. 两台电脑之间同样用配对码互相遥控；
5. 手机端数据加密存储。

## 常见问题

**Q：怎么升级到新版本？**
A：不用自己找安装包——软件检测到新版本会提示你，点更新后自动下载并弹出安装程序，下一步装完，数据全保留。

**Q：派出团队后箭头提前收口/少了人？**
A：已修复。还有问题就去「后台任务监控」看每个成员的状态。

**Q：父子对话的箭头点开说对方断连？**
A：已修复——箭头档案会保留并提示重新打开，消息不会丢。

**Q：派出前想换人？**
A：确认窗口那一步随便换，确认了才正式派。

**Q：科技树/总览面板位置重启后又乱了？**
A：位置已自动记忆。万一还有问题，一键恢复默认位置。

**Q：换电脑 / 旧版本的聊天记录怎么搬？**
A：文件菜单 → 万能导入，选旧目录或文件即可，支持从旧版本和其他 AI 工具搬聊天记录、密码库、记忆。注意：dsh 格式需要电脑装了 zstandard 库（没装会提示），codely 格式不用。

**Q：我的数据安全吗？**
A：全部本地运行；密钥只存本地受保护目录；手机端（峰控）数据加密存储；隐私台账（i 隐私）随时可查 AI 动过哪些敏感数据。
