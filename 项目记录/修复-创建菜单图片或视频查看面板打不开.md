# 修复-创建菜单图片或视频查看面板打不开（2026-08-27）
- 现象：双击画布 → 创建对话框 → 视觉 → 图片或视频查看，点击无反应、面板不出现，控制台无报错。
- 排查：app-imageviewer.js / app-kitecanvas.js（data-visual=viewer → ImageViewer.show）链路均正常，语法校验通过。
- 判定原因：① 面板挂在 canvasContent 且位置记忆在 UserSettings/localStorage，若保存坐标在当前视口外则打开后完全看不到；② 浏览器可能缓存旧版 JS。
- 修复：
  - app-imageviewer.js openPanel()：打开时检测记忆位置是否超出画布可见范围，超出则重置回视口右上角；并强制 zIndex=10010。
  - index.html 版本号强制刷新缓存：app-imageviewer.js v=5→v=6，app-kitecanvas.js v=17→v=18。
- 验证：node --check 通过。请刷新页面(Ctrl+F5)后重试。
