# 统一端口拉线管线（小圆圈 → 3px 连线 → 对话框）

## 需求
图片生成/视觉相关的对话框，从左右小圆圈端口拉出时统一走同一文件管线：
- 按下端口 → 拉出一条宽3的贝塞尔预览线
- 松开 → 在鼠标位置弹出对话框/面板
- 点空白处可关闭菜单（原有 dismissOnOutsideClick 已覆盖）

## 排查结论（app-kitecanvas.js）
- 文本节点输出圆圈 bindTextOutput / 媒体节点小圆点 node_ports_setup：有拉线但各自手写实现。
- 文生图面板端口 bindAuxPort（左入=提示词、右出=查看）：无拉线预览；面板位置固定偏移(clientX-328/clientY-90)，不在鼠标位置。
- openImagePanel 内 outPort 存在一段被 stopImmediatePropagation 拦截永远不触发的死代码（旧建图逻辑）。

## 修复
1. 新增 bindPortLinkDrag(port, onRelease)：统一的「端口→3px .kite-curve 预览线→松开回调(端口中心/画布坐标/视口坐标)」管线。
2. bindAuxPort 改为调用 bindPortLinkDrag，松开后在鼠标释放位置打开辅助面板。
3. openImageAuxPanel 面板位置改为精确出现在鼠标释放点（去掉 -328/-90 偏移）。
4. 删除 openImagePanel 中 outPort 的旧 mousedown 死代码。
5. bindTextOutput、node_ports_setup 的出点拖拽均改为调用 bindPortLinkDrag。

## 效果
所有端口拉线均为 stroke-width:3 统一样式；松开后提示词面板出现在鼠标位置；语法 node --check 通过。
