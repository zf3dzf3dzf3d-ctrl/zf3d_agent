# 修复：切换模型后对话无法停止

- 日期：2026-08-27
- 现象：模型切换时重置了 `chat.isSending`，但既有请求的 `AbortController` 和 Agent 循环仍可能继续运行，停止按钮因此失效。
- 修改：
  1. `public/js/agent-00-发送到模型_Agent_循环__发送状态管理_更新标题栏状态.js`：`stopSending()` 不再仅依赖 `isSending`，存在活动 AbortController 时也会执行中止；`_agentLoop()` 入口增加 `chat._stopped` 保护，阻止停止后的循环继续处理。
  2. `public/js/chatbox-01-底部模型选择器_增强版下拉__拖拽头部排除区域_刷新所有已存.js`：切换模型前先调用 `chat.stopSending()`，再执行会话状态重置。
- 验证：已对两份 JavaScript 文件执行 `node --check`，结果为 `ALL_OK`。
- 备份：两次 `replace_text` 均自动生成了带时间戳的 `.bak` 备份文件。
