# 设置面板穿透 + 隐藏模型图标与隔离修复（2026-08-27）

## 问题
1. 设置面板打开时，下层对话圆圈/风筝龙头仍可点击
2. 模型"隐藏此模型"按钮用 ● / ○ 图标不直观

## 根因与修复
1. **穿透**：app-kite.js 的 installPointerProxy 在 document 捕获阶段按坐标强行转发指针事件给风筝节点，绕过了 overlay 遮罩。修复：新增 inOverlay() 判断，pointerdown/pointermove/finish(pointerup) 三处均拦截 `.overlay.show / .settings-modal.show / .kite-modal` 命中时不转发。
2. **图标**：model-config-rewrite.js L161 visible 按钮 ○/● 改为 👁(显示中)/🙈(已隐藏)。
3. **隐藏隔离**：核查确认双击创建面板(app-kitecanvas.js fillModelList)、底部增强选择器(chatbox-01)、对话下拉、App.modelOptions(app.js)均已按 m.visible !== false 过滤，设置面板列表不过滤 —— 行为已符合要求。
