# 导航修复记录

## 2025-xx 修改：导航小圈仅成功时显示绿色（且仅激活框可见）

### 需求
对话框旁边的小圈（.chatbox-nav-arrow 左右导航圆圈）：
1. 只有旁边邻居对话**任务成功**时才出现**绿色**小圈
2. 其他状态（error/sending/queued/idle 等）一律**不出现**
3. 只有**当前对话框激活**（.active）时才显示

### 修改文件
1. `public/js/app-chatbox.js`（_updateNavArrowStatus，~617-629行）
   - 原逻辑：有邻居就显示，颜色随邻居状态（绿/红/橙/黄/蓝）
   - 新逻辑：邻居状态 === 'success' -> 加 `nav-success`（绿）；否则加 `nav-none`（隐藏）
2. `public/css/style-chatbox.css`
   - 第972行：`.chatbox:hover .chatbox-nav-arrow:not(.nav-none)` -> `.chatbox.active .chatbox-nav-arrow.nav-success`（仅激活框显示绿圈）
   - 第1025行：`.nav-none` 从半透明灰（opacity 0.3）改为 `display:none !important`（完全隐藏）

### 验证
- node --check 语法通过
- 备份：app-chatbox.js.bak_navcircle / style-chatbox.css.bak_navcircle

### 恢复方法
```
copy public\js\app-chatbox.js.bak_navcircle public\js\app-chatbox.js
copy public\css\style-chatbox.css.bak_navcircle public\css\style-chatbox.css
```
