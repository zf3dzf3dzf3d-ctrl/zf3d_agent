
## 2026-04 工具面板统计图表 + 复制按钮

### 需求
对话头部 🔧 工具图标点击打开的面板中：
1. 增加工具数量统计、使用最多的工具排行（占比图表）
2. 增加复制按钮：一次复制全部统计内容
3. 复制范围 = 使用频率排行 + 出错工具及具体错误内容（运行成功的工具不进入复制明细，方便排错）
4. 面板内错误摘要展示最近一次错误，复制时列出全部错误

### 技术要点
- 数据源是 DOM 里的 .tool-wrap 卡片（重启后不重建，统计仅限当前会话新增的工具调用，与原有徽章计数行为一致）
- 复制格式（纯文本，方便贴给 AI 排错）：
  ===== 工具使用统计 =====
  总调用: N 次 | 工具种类: N 种 | 出错: N 处
  【工具使用频率排行】 1. tool_name  ███ 3次 (30.0%)
  【出错工具明细】 ● tool（失败 N 次） [1] 具体错误内容
