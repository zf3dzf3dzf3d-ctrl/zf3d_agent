# 用户设置统一文件存储（private/用户设置/）

## 架构
- 后端：server/handler_routes.py 提供 `GET/POST /api/user-settings`，读写 `private/用户设置/user_settings.json`（POST 合并写入，null=删除 key）。
- 前端统一入口：public/js/user-settings.js，`UserSettings.get/set/remove/flushNow/loadFromServer`。
  - localStorage 键 `zf3d_user_settings_mirror` 仅作秒开缓存镜像，服务器数据到达后覆盖；写入双写+400ms 防抖合并 POST；beforeunload 用 sendBeacon 兜底。
  - index.html 已引入该脚本（v=1），位于 theme.js 之前。
- 迁移方式：拷贝 `private/用户设置/` 文件夹即可。

## 已迁移的设置（全部走 UserSettings，localStorage 仅缓存/备份）
- taskPanelWidthOffset（app-taskpanel.js 任务面板宽度偏移）
- active_project_id（app-project.js 活动项目，DB 优先）
- zf3d_lastBoxSize（chatbox-00 新建窗口尺寸记忆）
- zf3d_create_panel_w/h（app-kitecanvas.js 创建对话框 400×290）
- zf3d_image_w/h/model（app-kitecanvas.js / app-canvas.js / app-panels.js / app-imagenode.js 文生图设置）
- project_panel_width（app-project.js 项目面板宽度）
- zf3d-kite-face、zf3d-kite-anchor（app-kite.js 风筝龙头表情与拖拽位置）
- zf_theme（theme.js 日夜主题+主色，本次补齐双写 UserSettings + localStorage，_load 优先 UserSettings；reset_theme=1 时两者都清）
- appLang（i18n.js 语言，本次补齐：读取优先 UserSettings，切换时双写）

## 未迁移（有意保留）
- zf_compress_mode / zf_history_mode：已走服务端 DB kvSet + localStorage 双写（agent-01），属对话库逻辑，不进用户设置文件。
- IMAGE_ASSET_STORAGE_KEY（app-imagenode.js）：图片资产数据量较大，属数据非设置。
