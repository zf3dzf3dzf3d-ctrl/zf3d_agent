# 双击创建对话框按模态分组（文本/图像/语音）

## 需求
双击画布弹出的「💬 创建对话框」面板中，模型不再同列混排，按 文本/图像/语音 分组展示（火山方舟视觉、火山方舟语音等与文本模型分开列）。

## 实现（public/js/app-kitecanvas.js）
- chat builder 的 fillModelList 重写：CATEGORY_ORDER = [text/image/voice]，modelCategory(m) 判定：
  - imageGen=true 或 endpoint 含 /images/ → 图像
  - endpoint/modelId 含 tts/speech/audio/asr/whisper → 语音
  - 含 embedding → 暂不展示（向量化模型）
  - 其余 → 文本
- 分组标题样式 .kite-chat-group-title 新增
- 分组内模型点击仍调 App.createChatBox 创建对话框
- index.html 缓存版本 app-kitecanvas.js v4→v5

## 验证
- node --check 语法 OK
- 当前 6 个模型分到：文本(火山方舟/火山Coding Plan/Miaomio)、图像(火山方舟视觉 Seedream)、语音(火山方舟语音)、向量化(隐藏)
