# 文生图：设置持久化 + 视觉模型联动

## 用户需求
1. 文生图的尺寸和大模型记住上一个设置，关闭智能体也要记住（持久化）
2. 和视觉模型联动：可设置大模型（火山方舟视觉 Seedream 5.0 Lite 等），按具体模型id调用，交互与对话面板类似

## 实现
### 持久化（localStorage，关闭应用仍保留）
- 键：`zf3d_image_w` / `zf3d_image_h` / `zf3d_image_model`（模型键与设置面板 renderImageModelSelect 已有的 zf3d_image_model 共用，全局一致）
- 三个入口都记住：双击菜单文生图面板、文本节点右键文生图面板（app-kitecanvas.js）、右键菜单文生图（app-canvas.js，读上次设置）
- 关闭(✕/取消/生成)时都会保存

### 视觉模型联动（前端）
- app-kitecanvas.js 新增 `fillImageModelSelect()`：从 Models.list 的 imageGen 模型动态填充下拉（火山方舟视觉 (Seedream 5.0 Lite) 等），保存值不在列表时自动补选项；Models 异步加载完成后重填
- 与设置面板「image-model-select」共用 zf3d_image_model，选一次全局生效

### 后端
- `tool/coding/backend/image_gen.py`：
  - `_ark_image_models()`：从 models.json(经 model_config.load_models_config 的 list) 取 imageGen 模型 → {modelId: {endpoint,key,name}}，key 缺失时从 private/api_keys.json 按名称取
  - `_ark_generate()`：POST 火山方舟 `/images/generations`，Bearer key；Seedream 5.0 Lite 要求总像素≥3686400，小于自动等比放大；size 格式 `WxH`（不支持 `*`）
  - handle()：model 匹配 imageGen 模型（或 doubao-seedream/doubao-seed 前缀）时走火山方舟；否则回退 pollinations
- `server/handler_routes.py` `/api/image-gen`：改为统一转发到 tool 注册表的 image_gen 后端（原来 import image_gen 模块不存在会 500），status 返回 providers；agent-02 的聊天生图拦截走此路由，因此视觉模型在聊天里也生效

## 验证
- py_compile 两个 py 通过；两个 js 用 node new Function 语法检查通过
- 真实调用测试：`doubao-seedream-5.0-lite` 生成 1024x1024 → 实际 1920x1920（最低像素限制），返回 ark TOS 图片 URL ✅

## 涉及文件
- public/js/app-kitecanvas.js（两个文生图面板：持久化+视觉模型下拉）
- public/js/app-canvas.js（右键文生图读上次设置）
- tool/coding/backend/image_gen.py（火山方舟视觉模型调用）
- server/handler_routes.py（/api/image-gen 路由转发）
