# 对话模式限制规则系统（chat_mode_rules）

## 功能概述
按对话模式（1=直接聊天，2=工具循环）分别施加限制规则。规则集中在 `private/chat_mode_rules.json`，**默认值全部放宽到系统上限（几乎无限制）**，后期可逐项收紧。

## 文件清单
| 文件 | 作用 |
|---|---|
| `private/chat_mode_rules.json` | 规则配置文件（唯一调整入口，UTF-8） |
| `server/chat_mode_rules.py` | 服务端强制执行模块（读/校验/执行/保存） |
| `server/handler_routes.py` | 接入点：import + enforce + 路由 + 超时 |
| `public/js/db.js` | 前端规则加载（30秒轮询 + getModeLoopRules） |
| `public/js/app-agent.js` | _getContextLoopConfig 按模式覆盖 loop 参数 |

## 规则结构
```
global.request        全局请求限制（消息数/单条字符/请求总长/工具数/超时秒数）
modes.1.request/loop  模式1（直接聊天）专属限制
modes.2.request/loop  模式2（工具循环）专属限制
loop.steps            read/think/tools/observe/compress 各步骤开关+最大执行数
```

## 调整方法
- **直接编辑** `private/chat_mode_rules.json`（保存即生效，服务端热更新自动重载）
- **API**: `GET /api/chat-mode-rules` 读取；`POST /api/chat-mode-rules` 提交 `{"rules": {...}}` 整体写入
- **关闭某项限制**：字段改 `null` 或删除 = 恢复系统内置默认值
- **彻底禁用工具**（模式1推荐）：`modes.1.request.max_tools_in_request = 0`
- loop 段前端生效方式：30秒自动轮询 / 刷新页面立即生效

## 系统上限参考（最宽松值）
- max_agent_rounds: 1000（前端硬上限）
- loop_break_limit: 50
- context_token_budget: 200000
- tool_result_max_chars: 50000

## 生效机制
1. **request 段**：服务端 `_handle_proxy` 强制执行（所有 AI 请求必经点），超限直接 400 拒绝，工具数为 0 时剥离 payload 里的 tools
2. **loop 段**：前端 `_getContextLoopConfig` 读取并覆盖（对话级模式优先，全局兜底）
3. **请求超时**：`get_request_timeout(loop_mode)` 动态取值
