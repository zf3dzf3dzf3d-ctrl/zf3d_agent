# 图片修改对话框（多图输入 @图片N 引用）

## 需求
类似文生图的新对话框：左侧可导入 1~N 张图片，按导入顺序（上→下、左→右）自动编号「图片1、图片2…」，提示词中用 @图片N 引用对应图片，生成一张新图片上画布节点。

## 实现
### 前端 public/js/app-kitecanvas.js
- 双击菜单「创建对话框」视觉栏新增 🖍️ 图片修改（data-visual="edit"），点击调 openImageEditPanel()
- 新增 openImageEditPanel()：复用 kite-image-panel 样式体系，包含：
  - 左侧多图导入区（缩略图+编号 图片1..N + @插入按钮 + 删除按钮），空态显示用法说明
  - 导入方式：文件多选按钮 / 直接粘贴、拖拽到提示词框；最多 8 张
  - 行可拖拽排序（编号随位置重排）；双击缩略图放大查看
  - 「@」按钮把 `@图片N` 插入提示词光标处；计数行显示当前编号清单
  - 尺寸/大模型与文生图共用持久化设置与 fillImageModelSelect
  - 结果走面板→图片节点持久连线，未连线时自动在右侧建节点
- 新增共享函数：renderEditRows/readFilesAsDataUrls/bindImageEditControls/insertAtRef/normalizeDataUrl
- 生成请求：POST /api/tools/image_gen，payload={action:'edit_multi', prompt, size, model, image_urls:[dataURL...]}

### 后端 tool/coding/backend/image_gen.py
- handle() 新增分支：action='edit_multi' 或 image_urls≥2 时走多图编辑
- _chat_models_from_config()/_match_chat_model()：从 models.json 取对话系模型（跳过 /images/ 端点），Key 缺失回退 api_keys.json
- _multimodal_image_edit()：OpenAI 兼容 chat/completions 多模态消息（text+N×image_url，按传入顺序在系统前缀中编号），优先 message.images 提取图片，其次文本内 dataURL/markdown/裸 URL 正则提取
- 未匹配到模型时返回明确错误提示去模型配置添加

## 验证
- py_compile 与 node --check 通过
- __test_image_edit.py mock 测试通过：2 张参考图正确入 content、编号前缀含"图片1、图片2"、markdown URL 提取成功、Bearer Key 来自真实配置（匹配 claude-sonnet-4-6）
- 多选文件的浏览器原生顺序不保证跨平台一致，行拖拽可手动调整顺序后再生成
