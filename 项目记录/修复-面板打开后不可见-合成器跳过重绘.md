# 修复：项目管理/任务清单/对话清单面板打开后不可见

## 问题
1. 右上角项目图标点击 -> 项目管理面板"打不开"
2. 右下角任务清单、对话清单按钮点击 -> 面板"打不开"
3. 但打开设置面板后，这些已打开的面板就会显示出来

## 根因（Chromium 合成器渲染 bug）
面板默认 `transform: translateX(100%)` 位于视口外，浏览器合成器**跳过其图层创建/重绘**。点击按钮后 JS 正确添加了 `.open` class（`translateX(0)`），DOM 状态正确，但合成器未触发重绘 -> 面板"状态开了但画面没画"。

设置面板 `.overlay`（css/style.css L2352）带有 `backdrop-filter: blur(2px)`，打开时**强制整页重绘**，把被跳过的面板一起"刷"出来了——这就是"点设置后才显示"的原因。

佐证：之前有人在内联样式里加过 `#taskPanel/#projPanel { transform: translateX(100%) !important; }` 强制覆盖（现已在 diff 中删除），说明该问题反复出现过。

## 修复（双保险）
### 1. CSS：提升为独立合成层
- `public/css/style-project.css` `.proj-panel` 加 `will-change: transform`
- `public/css/style-taskpanel.css` `.task-panel` 加 `will-change: transform`
  → 面板常驻独立合成层，合成器必须跟踪其 transform 变化，不会再跳过重绘。

### 2. JS：打开后强制回流（reflow）
- `public/js/app-project.js` `openProjectPanel()`：`panel.classList.add('open')` 后加 `void panel.offsetWidth;`
- `public/js/app-taskpanel.js` `openTaskPanel()`：同样加 `void panel.offsetWidth;`
  → 强制浏览器立即重算样式，确保 transform 变化被应用到帧。

### 3. 版本号升级（强制刷新缓存）
index.html：style-project.css v2→v3、style-taskpanel.css v18→v19、app-project.js v2→v3、app-taskpanel.js v20→v21
