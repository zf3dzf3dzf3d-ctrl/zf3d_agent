# 视频生成修复记录 2026-08-27

## 问题
- `/api/video-gen`、`video_gen`、`video_status` 工具全都 `import video_gen`，但项目内不存在该模块 → 视频永远报"模块不可用"

## 渠道实测结论
- 火山方舟 plan key（当前"火山方舟"key）：❌ 不支持 seedance 视频模型（UnsupportedModel/agent plan），仅生图(Seedream)可用
- 硅基流动：无有效 key（401）
- pollinations：无视频端点（video.pollinations.ai 域名不存在）
- miaomio：仅文本+图像模型，无视频
- ✅ 智谱 CogVideoX-3：可用！POST /api/paas/v4/videos/generations 提交 → 轮询 /async-result/<id> → SUCCESS 返回 mp4

## 改动文件
1. **新增 `tool/video_gen_engine.py`** — 真实引擎：
   - `_video_models()` 从 private/api_keys.json 自动发现渠道（zhipu/siliconflow/ark）
   - `generate_video()` 多渠道自动切换，zhipu 默认主力（异步提交+轮询≤330s）
   - `video_status()` 渠道状态；`generate_video_from_task()` 查询已有任务
2. **重写 `tool/coding/backend/video_gen.py`** — 引用引擎，返回统一 videos 数组格式
3. **重写 `tool/coding/backend/video_status.py`** — 引用引擎
4. **修改 `server/handler_routes.py`（约1618行）** — `/api/video-gen` 路由改用 video_gen_engine

## 验证结果
- 工具 handler 直调：✅ status 正常
- HTTP /api/video-gen 真实生成：✅ cogvideox-3 出片 mp4 URL
- HTTP 生图回归：✅ pollinations 正常（未受影响）

## 注意
- 视频带水印（智谱免费渠道特性）
