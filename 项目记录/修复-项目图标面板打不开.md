# 修复：右上角项目图标（项目管理面板）点击打不开

## 问题
点击右上角📁「项目管理」图标，面板状态已切换但画面不显示（双击画布菜单里的"项目管理"也无效）。

## 根因
Chromium 合成器渲染 bug：
- `.proj-panel` 初始 `transform: translateX(100%)` 位于视口外
- 浏览器优化跳过其图层创建/重绘
- 点击后 `classList.add('open')` 虽然改了 class，但合成器未触发重绘
- 佐证：打开设置面板（`.overlay` 有 `backdrop-filter: blur(2px)`，强制全屏重绘）后，项目面板"跟着"显示出来

## 修复（三层防护）

### 1. CSS 层（style-project.css:24 / style-taskpanel.css:104）
```css
.proj-panel {
    transform: translateX(100%); transition: transform 0.3s ease;
    /* 修复：提升为独立合成层，防止合成器跳过重绘导致面板打开后不可见 */
    will-change: transform;
}
```
任务面板 `.task-panel` 同样处理。

### 2. JS 层（app-project.js openProjectPanel）
```js
panel.classList.add('open');
void panel.offsetWidth;                    // 强制同步回流
panel.style.transform = 'translateX(0)';  // 内联 transform 直写
panel.getBoundingClientRect();             // 触发布局读取
```
closeProjectPanel 中对应清理：`panel.style.transform = ''`。

### 3. 缓存层（index.html）
版本号升级强制浏览器拉新文件：
- `css/style-project.css?v=2` → `?v=3`
- `js/app-project.js?v=2` → `?v=3`

## 修改文件

- public/css/style-taskpanel.css（+will-change）
- public/js/app-project.js（openProjectPanel 强制回流+内联 transform；closeProjectPanel 清理）
- public/index.html（版本号 v3）
