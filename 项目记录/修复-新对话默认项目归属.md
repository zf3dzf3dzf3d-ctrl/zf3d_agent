# 修复:新对话应自动归入项目面板设置的默认(活动)项目

日期:2026-04-23
版本:5.0.1 补丁

## 现象
新对话框(如 cb19、cb20)创建后未归入项目面板设置的"当前项目"(●单选那个项目),落入未分类;而其他对话(cb17、cb18、cb21+)都正常归入 proj_1787727512561。

## 根因
新建对话的自动归入逻辑(`createChatBox`)依赖内存变量 `App._activeProjectId`,该变量由 `_loadActiveProject()` 异步恢复:
1. 先同步读 localStorage(`active_project_id`)
2. 再异步请求 DB(kv_store 表的 `active_project_id`)

**启动竞态窗口**:页面刚加载、`_loadActiveProject` 的异步结果尚未返回(且 localStorage 缓存缺失/未写入)的瞬间创建新对话,`_activeProjectId` 为 null → 归入逻辑被跳过,对话直接落到未分类。DB 日志佐证:cb19/cb20 的 `create` 后无 `project-auto` 记录,而正常对话成对出现。

## 修复(三层兜底)
### 1. public/js/app-chatbox.js(createChatBox 内,~194-249 行)
- 第一层:内存 `_activeProjectId`(正常路径)
- 第二层:内存为空时**同步**读 localStorage `active_project_id`,读到即回填内存并归入(毫秒级,消除竞态窗口)
- 第三层:两者都空时异步 `DB.getActiveProject()`,拉到后回填内存+localStorage,并对刚创建且仍无归属的对话**延迟补归**(含 DB.setNodeProject + 按钮刷新 + project-auto 日志)

### 2. public/js/app-project.js
- `_loadActiveProject()`:DB 值异步到达后追加 `.then()` 刷新面板高亮(单选圆点)和所有对话框的项目按钮显示
- 新增 `_updateAllChatProjectBtns()`:批量刷新所有对话框的项目按钮显示

### 3. public/index.html
- app-chatbox.js?v=470 → 471
- app-project.js?v=4 → 5(强制浏览器拉新缓存)
