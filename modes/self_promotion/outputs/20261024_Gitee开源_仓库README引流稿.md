# Gitee 开源仓库 · 引流 README 草稿

> 用途：把项目开源到 Gitee，承接搜索流量 + 给短视频"扣字领地址"提供落地页。

## 标题区
**朱峰智能体无限** — 把一群 AI 平铺在无限画布上同时干活的本地智能体平台。

## 一句话卖点（搜索引擎友好长尾词埋这里）
不同于单窗口 AI 助手：多策划 + 多审核 + 总结师流水线，几十个会话并发不卡顿，断网续读不丢进度，本地运行开源可改。

## 这能解决什么
- 痛点：和 AI 聊天要一句一句等，复杂任务来回补 prompt，多任务无法并行。
- 方案：把任务平铺到画布，多角色自动迭代到 90 分再交付，人只做点选。

## 30 秒上手
1. 克隆仓库 / 下载发行包
2. 配置本地模型或 API key
3. 双击启动，打开画布，开第一个智能体
