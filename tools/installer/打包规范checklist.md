# 安装包制作规范 checklist（防中文乱码 · 硬性门禁）

> 来源：5.8.0 安装器在 Win11 出现正文方块乱码事故（2026-11-10）。
> 纪律：本文件任何修改必须用 write_file 工具写，**禁止 PowerShell/cmd 直写**（项目已有两次直写乱码事故）。

## 1. 模板与脚本编码
- [ ] 安装脚本一律从 `tools/installer/template.iss` 复制起步，不许从零手写
- [ ] 脚本保存为 **UTF-8 with BOM**（自检脚本会验 BOM 头）
- [ ] 编译器锁定 **Inno Setup 6.x Unicode 版**（已知可用版本记录在此：待首次使用后回填版本号）
- [ ] 所有新增文案只写在脚本内，不引用外部 ANSI 编码资源文件

## 2. 中文语言段（三根因之二）
- [ ] `[Languages]` 段必须含 `Name: "chs"; MessagesFile: "compiler:Languages\ChineseSimplified.isl"`
- [ ] `Default.isl`（英文）仅作后备，不得作为唯一语言

## 3. 资源文件（三根因之三）
- [ ] 安装包内引入的 .txt/.rtf/许可协议等资源文件，一律 UTF-8（或另存为带 BOM）编码
- [ ] 资源文件名与路径避免中文（防不同系统代码页路径解析差异）

## 4. 编译前自检（硬性，不过不发）
- [ ] 运行 `python tools/installer/check_installer.py <脚本.iss>`，退出码必须为 0
- [ ] 自检项：BOM 头存在 / 无 U+FFFD 与非法 UTF-8 / [Languages] 中文段存在 / Default.isl 不单独出现

## 5. 消费端试装（硬性，最后防线）
- [ ] 在干净 Win11（物理机或 Windows Sandbox）试装，**截图安装界面**存档
- [ ] 截图人工核对：标题与正文中文全部正常，无方块/问号/乱码
- [ ] 任何"编译通过即分发"都是违规——5.8.0 事故即反例

## 6. 排障（装好后仍乱码的备选假设）
若以上全过但用户端仍乱码，按序排查：
1. 用户系统缺中文字体（检查语言包安装）
2. 用户区域设置"非 Unicode 程序语言"异常（仅影响 ANSI 版安装器，Unicode 版不应中招）
3. 资源文件编码（回查第3节）

## 7. 归档
- [ ] .iss 脚本与 checklist 一起入库版本控制（5.8.0 脚本不入库导致无法复盘，禁止重演）
- [ ] 试装截图存 `tools/installer/试装截图/`，文件名含日期与版本号
