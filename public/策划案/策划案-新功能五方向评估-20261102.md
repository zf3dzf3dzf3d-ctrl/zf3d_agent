# 新功能提案：五个方向 × 真实代码锚点评估

> 2026-11-02 · 基于 5.8.0 实际代码勘察（非空想）。每个方向给出：现有基建锚点、增量、与已有策划案的关系、风险。
> 勘察事实：`server/swarm_pipeline.py` 存在（45993 字节，五阶段蜂群流水线+worktree 隔离+git 实据门禁）；
> `private/roles_db.json` 存在（角色库）；进化树三表（capability/capability_link/emergence_event）在 `private/db/zf3d_canvas.db`；
> 《策划案-进化师角色立项 v2.0》已定稿（P0课题池→P1判据→P2角色→P3定时进化阶段），存在 `public/策划案/`（或备份路径）。

---

## 方向1：智能体梦境模式（离线自我进化）
**本质**：智能体空闲时自动消化当日失败，早晨交《梦境报告》。
**锚点**：
- schedule 定时任务（已存在）
- capability_tree emerge/emerge_pending/confirm（涌现候选现成输入源）
- 调查黑板 project_record（已有素材）
**增量**：一个夜间编排任务（swarm_pipeline.py 加第 6 阶段，或独立 schedule 任务）+ 报告模板。
**⚠️ 撞车警示**：此方向 80% 与《进化师角色立项 v2.0》的 P3 重叠。进化师策划案明确"P3 依赖 P2 稳定运行 2 周"且 P0（课题池手工记录）还没跑出数据。
**结论**：❌ 不建议单独立项。应先推进化师 P0/P1，梦境模式留作 P3 的增强形态（夜间自动跑 vs 周任务手动跑，同一套输入输出）。

## 方向2：多智能体议会互辩
**本质**：复杂任务自动分裂三独立 agent 互攻方案。
**锚点**：swarm_pipeline.py 已是"策划(多人)→收口裁决→施工→审核(多人)"——**这就是议会**。策划阶段多份策划案互辩+裁决早已实现。
**结论**：❌ 已存在，不新。真正缺的是把「反驳师」思想注入审核阶段做"强制找茬轮"，但策划案已有反驳师落地记录，勿重复。

## 方向3：时间旅行调试器（对话快照回滚）
**本质**：每次工具调用前存完整状态链，用户说"回到第3步重试"→ 真实回滚。
**锚点**：
- 全局纪律已有 git 双快照机制（对话开始/结束快照 commit）
- swarm_pipeline.py 已有 `git worktree add`（P1.2 隔离，实锤存在）
- cli.run_once 完整 agent 循环可复用
**增量（真实新东西）**：
1. 工具调用粒度快照：在 agent 循环里每次工具调用前打 lightweight tag（`tl-<对话>-<步>`）或 `git stash create` 快照对象（不占工作区）。
2. 回滚 API：`git reset --hard <tag>` 或 worktree 切换 + 对话上下文截断到该步（chat 库已有 agent_turns 按 session 存）。
3. 前端：对话气泡上右键"从此步重试"。
**风险**：快照频率高 → 用 `git stash create`（只存对象不污染）+ 每对话保留最近 N 步，过期清理。
**评估**：✅ 全项目唯一真正的新范式，锚点全实锤，工程量中等（后端 ~200 行 + 前端交互）。

## 方向4：技能遗传算法（工具杂交）
**本质**：两个工具代码自动拼接出工具草稿，用户点确认。
**锚点**：tool_sources/ 目录（现有 JS 工具源）、tools-defs-categories.js 启用数组机制、emerge confirm 交互可复用。
**增量**：杂交编排器（读两个工具的前后端源 → LLM 拼接 → 生成工具源文件 → 前端确认后注册）。
**风险**：杂交产物大概率是垃圾（参数/依赖冲突），LLM 拼接成功率存疑。可与方向1共享"用户确认"闸门。
**评估**：⚠️ 亮点高但成功率未验证，建议降级为"工具改写建议器"（只建议不自动生成）。

## 方向5：感官广播站（主动播报）
**本质**：智能体定时巡检关注站点，变化时 TTS+画布主动喊人。
**锚点**：browser_control（站点记忆已有）、schedule、tts_stream（已存在）、画布动画。
**增量**：巡检配置 + 差异检测 + 播报触发链。
**评估**：✅ 可行、工程量小，但"震惊度"一般（本质是监控+通知的组合）。

## 总推荐
| 方向 | 新颖度 | 可行性 | 建议档位 |
|---|---|---|---|
| 1 梦境模式 | ★★★ | ★★★★ | ⏸ 并入进化师 P3（勿单独立项） |
| 2 议会互辩 | ★ | ★★★★★ | ❌ 已实现（swarm_pipeline 五阶段） |
| 3 时间旅行 | ★★★★★ | ★★★★ | ✅ 唯一真新范式，推荐立项 |
| 4 技能杂交 | ★★★★ | ★★ | ⚠️ 降级为"改写建议器" |
| 5 感官广播 | ★★ | ★★★★ | ✅ 可做，工程量最小 |

**最终建议**：先做 **方向3（时间旅行调试器）**，这是五者中唯一建立在"已有 git 快照纪律 + worktree 隔离"之上、且业界无同类产品的新交互。方向1 并入进化师既有节奏，方向5 作为顺手的小甜点。
