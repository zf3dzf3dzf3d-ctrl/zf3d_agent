# 图表与图片页专用手册（给大模型看）

> 本文是 PROTOCOL.md 的补充。模型写图表页/图片页前先读这里，能显著提升出图质量。
> 播放器内置了所有动画，模型**不需要**写任何 CSS/JS，只写 JSON。

## 一、图表动画（内置，翻到该页自动播放）
| kind | 动画效果 | 备注 |
|---|---|---|
| `bar` | 柱子从底部逐根"长出来"，数值随柱淡入 | 0.9s/根，逐根错开 |
| `line` | SVG 描线动画从左往右画出，数据点逐个弹出 | 折线带发光 |
| `share` | 横向占比条从左往右生长，标签先现、数字后亮 | 替代旧的环形图 |
| `radar` | 雷达多边形描线生长 + 填充渐显，顶点逐个弹出 | 值域 0~100 |
| ~~`donut`~~ | 已下线（观感差），旧 JSON 里的 donut 请改写为 `share` | |

翻页（←/→）到该页时动画会重新播放，形成"翻到哪演到哪"的节奏。

## 二、JSON 写法
```json
{ "type": "chart", "title": "标题", "chart": { "kind": "bar", "data": [ {"value": 89, "label": "5.1", "color": "#ffb020"} ] } }
```
- 简写合法：`{ "type": "chart", "kind": "bar", "data": [...] }`
- `color` 可省略，省略时用主题色自动生成；只在"强调某一项"时给单色
- `value` 必须是数字

## 三、各图表选型与规则
1. **比较多少** → `bar`：3~8 条最清晰，超 10 条请合并或分页
2. **趋势变化** → `line`：数据按时序排好序再写进 JSON
3. **占比/进度/各项达标情况** → `share`（横向占比条）：
   - 默认按最大值换算宽度（适合"完成度/评分"场景）
   - 加 `"mode": "percent"` 则按总和算百分比（适合"构成占比"场景）
   - 每行自动显示标签+数值，无需自己算百分比
4. **多维能力对比** → `radar`（雷达图）：4~8 个维度，每个 value 是 0~100 的数；适合"能力模型""产品对比"主题
5. **只有 1~2 个数字** → 别用图表，改用 `stats` 大数字页
6. 旧写法 `donut` 已下线，生成时一律用 `share`

## 四、图片页（三种版式）
1. **图片组合墙 `gallery`**：
```json
{ "type": "gallery", "title": "场景展示", "layout": "grid2",
  "images": [ {"src": "https://.../a.jpg", "caption": "入口界面"}, {"src": "...", "caption": "工作台"} ],
  "caption": "底部说明文字（可省略）" }
```
   - `layout`：`row`（1~2 张横排）/ `grid2`（2×2，3~4 张默认）/ `grid3`（3 列，5~9 张用）
   - 图片淡入弹出逐张错开，caption 覆盖在图底部渐变条上
   - `src` 支持网络 URL；模型没有可用图片时不要硬凑占位图，改用其他版式
2. **左文右图 `split`**（一图配要点，最常用的图文页）：
```json
{ "type": "split", "title": "标题",
  "bullets": ["要点一", "要点二"],
  "image": {"src": "https://..."} }
```
   图片从右侧滑入，左侧文字正常淡入。
3. **自由摆放 `scene`** 里的 `{"type":"image","src":...,"x":..,"y":..,"w":..,"h":..}` 元素：需要多图重叠、异形排版时用，支持 `enter` 入场动画和 `delay`。

## 五、示例（可直接粘贴测试）
```json

  {"value": 92, "label": "画布引擎"}, {"value": 78, "label": "演示系统"}, {"value": 65, "label": "语音链路"} ] }
```

```json
  {"value": 90, "label": "记忆"}, {"value": 85, "label": "工具"}, {"value": 70, "label": "规划"}, {"value": 95, "label": "响应"} ] }
```
