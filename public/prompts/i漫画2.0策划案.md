## 二、里程碑规划

### M-D1 本地下载器（P0，优先——"先做好这一件事"的地基）
- 每章/批量下载：走现有图片代理链，按 `server/data/comics_local/<source>/<mangaId>/<chapter>/` 落盘（图片JPEG/PNG原样存，metadata.json 记标题/章节/源）。
- 下载队列：进度条+暂停/续传（页面级索引文件断点）；失败重试 3 次。
- 下载完成后自动进「本地书架」，本地源适配器已能直接读，无缝衔接在线→本地。
- 合规：仅下载 MangaDex 公开 API 允许内容 + 用户自有本地文件；遵守源站限速（≤5req/s，串行小间隔）。

### M-D2 超级观看器升级（P0）
- 翻页：已有 pointer 拖拽/右开左开/条漫 → 增加 滚轮翻页、键盘←→、双指缩放。
- 双页模式（横屏宽窗时自动拼双页）、页面裁边/适应模式切换。
- 夜间模式（暗色滤镜）+ 亮度/对比度滑条。
- 阅读时浮动工具条：上一章/下一章/进度条跳页/下载本章。
- 预读 ±2 页已有 → 扩到本地源全章预载（本地无网络成本）。

### M-D3 改剧情「i模式」（P1，差异化核心）
- 阅读器内选中某页 → 呼出 AI 面板：「续写对话/改台词/脑补剧情/角色问答」。
- 台词气泡覆盖层：用户/AI 编辑的气泡以图层叠在原页上，可保存/分享/还原（原页不动）。
- 剧情 fork：每本漫画可有多个「剧本分支」，进入阅读器选择用哪个剧本看。
- 技术：气泡用 JSON（页码+坐标框+文本+说话人）存 `server/data/comics_scripts/<mangaId>/`；AI 生成走现有智能体链路；图片不改动，规避版权合成问题。

### M-D4 智能体搜集力（P1）
- 「帮我找漫画」：派智能体后台按描述搜多源（现有跨源合并搜索），整理成推荐清单（封面+简介+评分）。
- 追更哨兵：收藏的书有新章节时后台任务提示（复用 schedule）。
- 书架整理师：智能体扫描本地库，按题材/完结状态自动归类打标签。

### M-D5 漫画社交（P2，远期）
- 智能体荐书：i聊天广场里智能体互相推荐最近读的漫画。
- 分享改剧情剧本（气泡层 JSON 很小，适合分享）；分享下载清单（不含图，只含源+ID 元数据）。
- 用户上传自有漫画到本地共享区（合规：仅限自有版权/公版，先本地后联机）。

## 三、合规红线（沿袭 v3）
- 不内置盗版源；下载仅限合法来源；改剧情只做覆盖层不改原图；分享只传元数据/剧本不传图片文件。

## 四、开工顺序与验收

5. M-D5 视用户反馈再排期

## 六、窗口与对话协同（2026-11 用户补充需求，P0）
> 核心诉求：i漫画窗口与对话窗口**同屏共存**，让用户可以一边看漫画、一边命令对话去搜集/下载漫画，互不打断。

### M-W1 窗口可自由拖拽（P0）
- i漫画 Dock 窗口支持标题栏按住拖拽（自由定位画布任意位置）+ 拖到边缘可吸附。
- 位置/大小记忆（localStorage 或 server 配置），下次打开恢复上次布局。
- 支持窗口缩放（右下角 resize 手柄）与最小化到 Dock 图标。
- 现状基础：zf-app-dock.js 已有 register/可拖拽骨架，需验证拖拽手感并补齐记忆与 resize。

### M-W2 双窗共存（P0）——「边看边指挥」
- i漫画窗口停靠屏幕下方时，**上方的无限界面对话保持完整可见可交互**（两者不互相遮挡、不抢焦点）。
- 用户可在对话窗直接下指令（如"帮我搜集桂正和的全部章节并下载"），i漫画窗口实时展示搜集/下载进度，无需关闭或切换任何窗口。
- 焦点管理：漫画窗口阅读操作（翻页/滚轮）不抢对话输入框焦点；对话输入 Enter 发送不影响漫画阅读状态。
- 联动指令：对话智能体可通过现有工具链调用漫画端点（搜索/下载队列/书架），执行结果回写漫画窗口刷新书架。
- 布局建议：默认 i漫画窗口半屏停靠底部（高度约 45%），对话区占上方；用户可拖拽调整比例或拖离停靠位变浮窗。
- 验收：同屏状态下实测 ①对话发"找漫画"指令 ②i漫画窗口同步出现进度 ③两边同时操作互不干扰。

### 排期影响
M-W1/M-W2 与 M-D1/M-D2 同为 P0，建议实现顺序：M-W1（拖拽+记忆）→ M-D1（下载器）→ M-W2（双窗联动）→ M-D2（观看器）——先能"边看边指挥"，下载器才有最佳使用场景。
