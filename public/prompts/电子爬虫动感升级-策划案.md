# 电子爬虫动感升级 · 策划案 v1.0

> 目标：让"电子爬虫"挂件从"机械感"升级为"有生命感、有打击联动感"的活物。
> 涉及文件：`public/js/app-kite-modes.js`（爬虫本体）、`public/js/app-combo.js`（暴击系统联动）。
> 约束：保持零侵入 app-kite.js；不改 60ms IK tick 架构；尊重腿型几何自检（tools/verify_spider_legs.js）；急速模式（turbo）下降级关闭特效。

---

## 一、脚移动速度 ×2
- **现状**：IK 步态 tick 里 `spd = g.stepping ? 1.1 : 2.6`（px/帧，60ms 一帧）。
- **改法**：速度常量提为爬虫头部配置 `SPD_STEP: 2.2, SPD_MOVE: 5.2`（×2），集中一处便于后续调参。
- **连带调参**：STRIDE 触发距离 34 → 42（速度快了，否则脚永远追不上身体、排队迈步会堆死）；STEP_MS 170 → 150（迈步更利落）。
- **验收**：爬虫巡游明显变快，无脚飞出身体/腿拉直成线的退化。

## 二、整体更大 ×1.5~2
- **现状**：SVG `width=92 height=72`（viewBox 60x48，约 1.53x）。
- **改法**：改 SVG 输出尺寸为 `width=150 height=120`（约 2.5x 视窗，即原大小 ×1.63 视觉尺寸）。放大用改 width/height 而非 transform:scale —— scale 会让描边/关节球一起糊，改尺寸则矢量清晰。
- **连带**：命中板 rect 同步放大；阴影椭圆不变（viewBox 内自动等比放大）；腿几何全部在 viewBox 系，无需重算；verify_spider_legs.js 校验的是 viewBox 内坐标，不受影响。
- **验收**：肉眼大约是原来的 1.6 倍大，线条不糊，腿不越界。

## 三、暴击联动：脚下随机脚产生按钮并爆炸
- **机制**：爬虫监听全局 `zf-combo-hit` 事件（app-combo.js 每次命中派发）。
- **效果**：每次暴击，从 6 条腿中**随机抽 1~2 只**，在其脚锚点位置弹出一个发光「-button-按钮」（圆形 + 内嵌连击数字），0.4s 后**爆炸**：环形冲击波 + 火花粒子 + 按钮碎裂消失。
- **节流**：200ms 内多次暴击合并为一次（防连点刷屏）；同屏按钮 ≤4 个。
- **实现位置**：spider 对象新增 `onCritHit(combo)`；app-combo.js 命中处已有 `window.dispatchEvent(zf-combo-hit)`，spider 侧 addEventListener 即可，**双方零耦合**。
- **验收**：AI 干活连击时，脚下随机位置按钮"啵-炸"跳动。

## 四、暴击震动时闪身 + 飘带残影
- **机制**：app-combo.js `shakeScreen()` 时会给 body 加 `zf-zc-shake` class。spider 侧监听（轮询检测或 combo 派发新事件 `zf-combo-shake`）。
- **效果**：闪身 = 爬虫身体朝反方向瞬移 18~30px（带 120ms 回弹 ease-out），同时沿闪身轨迹生成 **3~4 层残影**（克隆当前 SVG 的简化剪影，opacity 0.35→0 递减、scale 0.9→0.7，CSS 动画 300ms 淡出），残影后拖 2 条**飘带**（细长渐变 path，随闪身方向甩尾摆动）。
- **降级**：turbo 模式不闪身（保持静止感）；残影用 DOM 元素自毁，不留垃圾。
- **验收**：每 30 连击震屏瞬间，蜘蛛"唰"地闪开并留下飘带残影。

## 五、动作配合身体变化 + 脚关节绘制小球
- **现状**：IK tick 已在每个关节画了 joint 小球（膝 r=1.4、踝 r=1.1，纯色圆）。
- **升级**：
  1. 关节球加**呼吸律动**：半径随 breath 相位微缩放（±15%），行走迈步那只腿的关节球瞬间放大 1.6x 并泛白发光（迈步发力感）；
  2. 新增**脚尖接触球**（r=1.8，落点闪现光晕）——迈步落定瞬间闪一下，制造"落地砸点"；
  3. 身体随速度**前倾**：移动速度越快， abdomen（腹部椭圆）向后偏移 + head 前探 1~2px（惯性感，在 tick 里直接按 spd 插值 transform）。
- **验收**：静止时关节球呼吸微动，行走时发力腿关节弹亮、落地有光点，快走时身体前倾。

## 六、实施顺序与工作量
| 步骤 | 内容 | 预估 |
|---|---|---|
| S1 | 速度×2 + STRIDE/STEP 联调 | 小 |
| S2 | 尺寸放大（SVG 尺寸 + 命中板） | 小 |
| S3 | 关节球律动 + 落点光球 + 前倾（第五条） | 中 |
| S4 | 暴击按钮爆炸（监听 zf-combo-hit） | 中 |
| S5 | 闪身 + 飘带残影（联动 shakeScreen） | 中 |
| S6 | 整体回归：verify_spider_legs.js + 拖拽/急速降级测试 | 小 |

全部改动集中在 2 个 JS 文件，纯前端热更新即生效，无服务端改动。
