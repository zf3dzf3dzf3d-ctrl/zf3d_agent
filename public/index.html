无套路，重任务！传统智能体 = 走路，朱峰智能体无限 = 飞行。
一个本地优先的智能体工作台，把多模型、多对话、长期任务、工具执行和无限画布放进同一个工作空间。

简介

有没有考虑过你的智能体，比如 Codex 或 Claude Code 该升级换代了？答案是：朱峰社区智能体无限全部做到了。

这个项目，诞生于它的上一个版本。最开始我们只做了三个工具：读取、写入、执行。经过几天时间，就创建了如此好用的朱峰社区智能体无限！
开发速度是惊人的，朱峰老师几乎同时可以操作至少 8–30 个窗口，以超级惊人的速度进行任务执行工作。朱峰社区智能体绝对是干活效率领先的智能体头部产品！

免费开源 · 支持多模型多对话 · Windows / Web 双端 · 零依赖启动（纯 Python 标准库，双击即用）。

八大核心特性

  • 🖼️ 无限画布：右键创建对话框，中键拖拽平移，随意缩放。小地图导航，双击展开菜单，任意创建会话，超级快。自由组织对话节点，哪个优先做、哪个之后做一目了然，最多可同时开启 400+ 个任务对话窗口。
  • 🧠 多模型连通：我不属于任何模型，每个会话走最佳线路。DeepSeek、通义千问、智谱GLM、豆包、Kimi、GPT、Claude、Gemini、腾讯混元、百度文心、本地Ollama，任意 OpenAI 兼容接口，哪个最强走哪个。
  • 🤖 Agent工具模式：AI不只是聊天。Agent 工具循环，让 AI 自主读写文件、运行代码、联网抓取、Git提交、定时调度、跨对话搜索、发邮件、管理记忆、向你提问。极简 29 / 编程 33 / 写作 58，三模式按需切换。
  • 📋 消息队列：随意聊，随意停，AI 不会忘记你的任何一条消息。AI 回复期间新消息自动排队，支持编辑/删除/自动发送。
  • 💾 SQLite 持久化：超快，超能大，大了自己分割。每 5 秒自动保存你的数据，对话永不丢失。后台离线自动回退本地存储，恢复后无缝切回。
  • ⚡ 零依赖启动：零依赖，纯 Python 标准库，双击即用。前后端分离，热更新改完即生效。模块化架构，app.js 拆 10 模块、server.py 拆 7 模块。
  • 🎨 界面体验：暗色主题、小地图导航、Markdown 渲染、代码高亮、Mermaid 图表。工具消息折叠，对话标题自动更新。
  • 🔒 安全隐私：密钥本地存储，界面日志全掩码，你的密钥不离开你的电脑。

❓ 使用帮助

从配置一个可用模型开始，再把复杂目标交给智能体拆解和持续执行。

五分钟快速上手

  1. 下载安装：从社区官网下载，解压后双击启动朱峰社区智能体无限，无需安装任何环境。
  2. 配置模型：打开设置 → 模型管理，填入任一 OpenAI 兼容接口的 Base URL 和 API Key（DeepSeek、智谱、Kimi、本地 Ollama 均可），密钥只存本机。
  3. 创建对话：在画布空白处右键（双击也可）→ 新建对话，选好模型和工具类型即可开聊。
  4. 下达任务：简单问题直接问；复杂目标写清楚背景与期望产出，交给智能体拆解执行。
  5. 并行扩展：继续右键创建更多对话，每个对话独立模型、独立上下文、互不干扰。

Agent 工具模式（三模式按需切换）

  • 📄 极简模式（29 个工具）：通用基础工具。文件读写、运行代码、联网抓取、Git提交、定时调度、跨对话搜索、邮件、记忆、项目记录等。
  • 💻 编程模式（33 个工具）：极简全部 + 编程专属。diff预览、Git日志、代码结构分析、文件移动。
  • ✍️ 写作模式（58 个工具）：41 个 AI 文本处理工具 + 极简全部工具。
  • 每个对话可在「对话设置 → 工具类型」中独立选择模式，控制该智能体可调用的能力范围。

常见问题

  • AI 回复时还能发消息吗？可以。消息自动进入队列，AI 处理完当前任务后按序接收，支持编辑和删除排队消息。
  • 任务失败怎么办？失败时会自适应重启对话，状态栏会显示失败原因供排查。
  • 数据保存在哪里？SQLite 本地数据库，每 5 秒自动保存；后台离线时自动回退 localStorage，恢复后无缝切回。
  • 修改代码要重启吗？不需要。前后端分离 + 热更新，改完即生效。
  • 怎么让多个 AI 一起干活？用风筝系统（monitor/chat_manage）把任务分派给其他对话，主对话守护监控并回收结果；也可以 shift+移动对话框复制会话做 A/B 对照。

功能导航

  • 1 设置颜色：在颜色设置中调整画布、面板、文字和强调色，保存后全局生效。
  • 2 项目设置：配置当前项目名称、路径、默认模型、工作目录和项目级提示词。
  • 3 设置面板：集中管理常用显示、自动保存、布局、工具结果保留和联网选项。
  • 4 网站登录：通过右上角登录入口管理账号状态；登录信息与本地工作区设置分开保存。
  • 5 底部排列：使用底部排列功能快速整理画布中的对话框，适合清理重叠节点。
  • 6 对话状态：查看等待、运行、完成、暂停、失败等状态，判断任务是否仍在执行。
  • 7 任务清单：把目标拆成步骤，逐项标记状态并跟踪长期任务。
  • 8 风筝系统：用于把任务交给其他对话协作、持续守护并回收执行结果。

对话设置

  • 标题：修改节点名称，便于在无限画布中定位任务。
  • 模型：为当前对话选择模型和线路，不影响其他对话。
  • 工具类型：按任务启用或切换工具类别，控制智能体可以调用的能力。
  • 当前项目：绑定项目上下文，让文件操作和任务记录落在正确项目中。
  • 工具展示：展开后可查看工具调用名称、参数、结果和执行顺序。
  • 上下文：当前对话发送给模型的近期消息与工作信息。
  • 对话历史：完整查看、搜索或恢复已经保存的消息。
  • 日志：查看运行过程、错误和系统事件，用于排查任务问题。

画布与排列

  • 平移与缩放：左键或中键拖动空白处平移，滚轮缩放画布。
  • 移动对话框：按住 Shift 再拖拽对话框，可直接移动节点，避免误触输入区。
  • 整理：拖动节点调整位置和尺寸，也可使用底部排列快速规整全部对话。
  • 状态：节点颜色和状态标识反映当前任务进度，打开对话可查看详情。

联网与安全

联网能力、API 密钥、额度和模型可用性由服务商决定。API 密钥不要写入对话、脚本、日志或截图。运行命令、修改文件、发送邮件前确认目标和范围，重要资料先备份，并明确限定允许访问的文件夹。发现目标不正确时立即暂停任务并要求停止。

开始使用

1. 在“模型配置”填写接口地址、模型 ID 和 API 密钥并保存测试。
2. 在画布创建或打开对话节点，选择模型后发送任务。
3. 把复杂目标拆成步骤，并明确说明需要读取、修改、搜索或运行的内容。

常用操作

画布：空白处拖动平移，滚轮缩放，节点可拖动整理。
对话：每个节点保留独立上下文，可新建分支和切换模型。
任务清单：拆分目标并跟踪完成比例。
自动化：使用定时任务执行、查看长任务。
备份：定期导出，恢复前先备份当前数据。

联网与安全

免费模型不代表一定无需密钥；401、额度或网络错误通常需要检查接口和服务状态。API 密钥不要写入对话、脚本或截图。运行命令、修改文件、发送邮件前确认目标和范围，重要资料先备份。

设置面板逐项说明

  • 模型管理：维护模型线路、接口地址、模型名和可用状态；会话可独立选模型。
  • 默认模型：新建对话使用的默认线路，不会强制覆盖已有对话。
  • API 配置：保存服务商连接信息；密钥属于敏感配置，不应写进日志、对话或版本库。
  • 本地优先：设置、会话和工作区优先落在本机，减少对云端历史的依赖。
  • 颜色主题：调整画布、面板、文字和强调色，形成个人工作环境。
  • 画布布局：通过无限画布组织多个对话节点，支持拖拽和底部排列。
  • 自动保存：降低浏览器关闭或任务中断造成的状态丢失风险。
  • 工具结果保留：控制上下文中保留多少工具结果，平衡可追溯性与上下文长度。
  • 日志面板：查看运行过程、错误和系统事件，定位模型、工具或网络问题。
  • 备份恢复：对工作区和设置进行备份，便于迁移或故障恢复。
  • 健康守护：按间隔提醒休息，并可设置连续工作阈值和强制休息时长。
  • 邮件通知：配置任务完成或异常后的邮件发送能力，依赖 SMTP 设置。
  • 网站登录：右上角账号状态与本地工作区设置分开管理，登录不等于 API 密钥。
  • 项目绑定：指定当前项目、路径、工作目录和项目级上下文。
  • 对话标题：为画布节点命名，便于检索、排列和协作。
  • 对话模型：在单个节点切换模型，适合研究、编程、审核分别选型。
  • 工具类型：按任务限制工具类别，减少不必要的权限和调用。
  • 工具展示：展开查看工具名、参数、结果和调用顺序。
  • 上下文管理：控制当前请求携带的工作信息与近期消息。
  • 对话历史：读取、搜索和恢复已经保存的消息。
  • 任务清单：把复杂目标拆为步骤，记录 pending、in_progress、completed 等状态。
  • 风筝系统：把任务交给其他对话，持续监控队列并回收结果。
  • 对话状态：区分等待、运行、完成、暂停和失败，帮助判断是否需要介入。

Gitee / GitHub 使用帮助

本应用支持一键保存到 Gitee/GitHub 远程仓库。先在这里了解它们是什么、如何选择，再前往「保存/发布」配置仓库地址。

🧭 Gitee vs GitHub 怎么选？

两个都是代码托管平台，选哪个看你的网络环境和使用场景。

Gitee 码云GitHub
所属开源中国（国内）Microsoft（国际）
访问速度国内直连，速度快需稳定国际网络
访问质量稳定，无需代理部分地区/网络不稳定
私有仓库免费（有成员数限制）免费无限私有仓库
适合人群国内开发者、内网环境国际协作、开源项目
💡 建议：如果你在国内、且只想备份项目，选 Gitee 更省心；如果要做开源、参与国际社区，选 GitHub。

📦 仓库地址是什么？

就是仓库主页浏览器地址栏里的那个链接，两种形式都可以：

  • HTTPS 地址（推荐新手）：形如 https://gitee.com/用户名/仓库名.git 或 https://github.com/用户名/仓库名.git
  • SSH 地址（推荐进阶）：形如 git@gitee.com:用户名/仓库名.git 或 git@github.com:用户名/仓库名.git
🔑 HTTPS 需要账号密码/Token；SSH 需要提前配置密钥（见下文 SSH 教程）。不确定就用 HTTPS + 私人令牌。

🎫 私人令牌（Token）从哪来？

远程推送需要身份验证，私人令牌比密码更安全。两步搞定：

  1. 登录 Gitee → 右上角头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌（勾选 projects 权限）。
  2. 登录 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → 生成新令牌（勾选 repo 权限）。
⚠️ 令牌只显示一次，生成后立即复制保存。泄露了可在同页面随时吊销重建。

🔗 SSH 密钥怎么配置？

一次配置，终身免密推送。四步完成：

  1. 生成密钥：ssh-keygen -t ed25519 -C "你的邮箱"（一路回车即可）
  2. 复制公钥：Windows 下打开 C:\Users\你的用户名\.ssh\id_ed25519.pub，复制全部内容。
  3. 添加到平台：Gitee/GitHub → 设置 → SSH 公钥 → 粘贴 → 保存。
  4. 验证连通：ssh -T git@gitee.com 或 ssh -T git@github.com，看到 "Hi 用户名!" 即成功。
✅ 配置成功后，仓库地址换成 SSH 形式（git@... 开头）即可免密推送。

🚀 常见问题

Q：推送时提示 Permission denied（publickey）？
A：SSH 密钥未配置或未添加到平台。按上方 SSH 教程重新检查第 2、3 步。
Q：提示 Authentication failed？
A：HTTPS 推送时密码应填私人令牌而不是登录密码（GitHub 已不支持密码）。
Q：remote 已存在 / 推错仓库了？
A：到「保存/发布」面板重新设置仓库地址即可，应用会自动更新远程地址。
