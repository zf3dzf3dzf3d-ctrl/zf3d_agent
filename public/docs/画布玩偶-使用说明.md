# 画布玩偶 · Canvas Doll 使用说明

无按钮 3D 角色浮层，叠在无限画布上，背景全透明，同屏只有一个角色。

## 文件
- `public/js/app-avatar-doll.js` — 玩偶模块（已挂载 index.html 尾部）
- `public/avatar-demo.html` — 独立测试页（旋转/平移/缩放/口型/VRMA 全功能演示）
- `public/assets/avatars/` — 放 .vrm 模型文件
- `modes/<角色>/manifest.json` — 角色形象配置

## manifest 角色接入
在任意角色 manifest.json 加（可选字段，不配则该角色不上场）：

```json
"avatar": { "vrm": "/assets/avatars/doll.vrm" }
```

## 控制台 API
```js
CanvasDoll.show('/assets/avatars/doll.vrm')  // 显示并加载模型
CanvasDoll.hide()                            // 隐藏（暂停渲染，省性能）
CanvasDoll.playAction('wave')                // wave/nod/happy/shy/angry/sleep
CanvasDoll.speak('你好')                     // TTS 出声 + 口型同步
CanvasDoll.move(x, y)                        // 移动（右下角基准，自动记忆）
CanvasDoll.onMode(id, manifest)              // 模式切换联动入口
```

## 特性
- 拖拽定位（拖角色本体），位置存 localStorage，刷新还原，默认右下角
- 同屏一个角色：模式切换时旧角色隐藏、新角色淡入
- 待机呼吸浮动、随机眨眼、点击说话、口型由 Web Audio 实时音量驱动
- 后端 TTS：`POST /api/avatar/tts` → 自动播放；失败兜底浏览器语音
- 隐藏时完全暂停渲染循环，不耗 GPU

## 动画扩展
- VRMA 骨骼动画：`playVRMA('/animations/xxx.vrma')`（demo 页），动画文件放 `public/animations/`
- 后续可接入英伟达开源动画器（如 Cosmos/Chunk Animator 类）批量生成 .vrma
