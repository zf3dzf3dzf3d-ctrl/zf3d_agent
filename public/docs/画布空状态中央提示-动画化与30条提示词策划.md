# 画布空状态中央提示 · 动画化 + 30 种轮换提示词策划方案

## 一、现状问题
- 空画布时中央仅一行静态文字（如「还没有任何对话 / 右键画布新建」），缺乏引导感与产品温度。
- 文案固定，看久了变成"视觉噪音"，用户直接忽略。
- 与项目已有的动效资产（粒子背景、星空、极光、3D 场景）风格不联动。

## 二、优化目标
1. 空状态即"欢迎页"：一眼知道「这里可以做什么 + 怎么开始」。
2. 每次进入/清空画布，提示词都不同 → 新鲜感 + 功能曝光。
3. 动画轻量（纯 CSS/少量 JS），不影响画布性能，有对话后立即隐藏。

## 三、动画化方案（三档可选）

### 方案 A：轻量 CSS 动画（推荐首选，零依赖）
- 结构：主标题 + 副标题 + 3 个快捷提示气泡（chips）。
- 动效：
  - 主标题：逐字上浮淡入（stagger 0.05s/字），带轻微 letter-spacing 收缩。
  - 下方光标"▍"闪烁（打字机呼吸感）。
  - 3 个提示 chip 依次弹出（scale 0.8→1 + 上移），悬停时浮起发光。
  - 背景一圈极淡的呼吸光环（radial-gradient 脉动，8s 周期）。
- 点 chip 直接把该提示词填入新建对话 → 引导即转化。

### 方案 B：打字机轮播（次选）
- 一条提示词逐字打出 → 停留 3s → 逐字删除 → 换下一条。
- 适合空间小的场景，但等待感略强。

### 方案 C：Canvas 粒子聚字（炫技档）
- 复用项目已有 engine2d 粒子：粒子从四周汇聚成主标题字形，鼠标靠近散开。
- 视觉最惊艳，成本最高，建议作为"探索模式/节日彩蛋"开关。

**建议落地**：默认方案 A，预留 C 为可选开关；A/C 共用同一份提示词池。

## 四、30 种轮换提示词（每次随机 1 主 + 3 快捷 chip）

主标语池（分风格混搭，避免同质）：

【功能引导型】
1. 双击画布任意处，创建你的第一个对话
2. 右键画布，唤出全部能力菜单
3. 拖入一张图片，让我帮你看看
4. 按 Ctrl+S，随时保存整块画布
5. 试试 Tab 键，极速创建并发送对话
6. 把任务交给我，你可以去喝杯咖啡
7. 多开几个对话，看它们并排干活
8. 长任务交给风筝系统，它替你盯着

【创意灵感型】
9. 一个想法，值得从一行提问开始
10. 空白画布 = 无限可能，从哪开始都行
11. 今天想造点什么？游戏、网页还是工具？
12. 说一句"帮我写个贪吃蛇"，剩下的交给我
13. 灵感稍纵即逝，先打下来再说
14. 你的下一张画布，何必只是画布

【陪伴语气型】
15. {时段好}！我在这儿，随时开工
16. 画布空着没关系，我们聊两句就有了
17. 别客气，第一个问题问什么都可以
18. 深夜了？我知道很多适合睡前折腾的小项目
19. 新的一天，新的画布，新的可能性

【能力展示型】
20. 我会写代码、做网页、剪辑视频、抓网页……
21. 本地运行，你的数据不出这台电脑
22. 无限画布 × 无限对话 × 无限可能
23. 试试："帮我总结这个文件夹里的文档"
24. 从一句话到一个可运行的小游戏，只要几分钟

【趣味人格型】
25. 嘿，我发现一块空画布——侵略它！
26. 我刚充好电，正愁没活儿干
27. 据说敢在空画布上双击的人，运气都不会差
28. 这里安静得能听见代码生长的声音
29. 空画布恐惧症？点我即可治愈
30. 朱峰待命中：输入你的脑洞，剩下的我来

快捷 chip 池（从下面取 3 个与主标语不重复的组合）：
- 「帮我写个小游戏」「总结一个文件夹」「做个个人主页」「翻译这段话」
- 「抓取这个网页」「画一张图」「写周报模板」「做个数据表」
- 「配置我的模型」「新建定时任务」「开局demo」「随便来点有趣的」

## 五、轮换逻辑
1. 池子按「类型 ≥ 5 类」分层随机：先抽类型，再抽该类文案 → 避免连续同类。
2. 用 sessionStorage 记最近 3 条已展示，抽签时排除 → 保证"每次都不同"。
3. 时段问候类（15/18/19）动态拼接：凌晨好/早上好/下午好/晚上好 + 星期。
4. 节日彩蛋位：预留 2 个槽位，按日期覆盖（春节/中秋等，后期扩展）。

## 六、触发与隐藏
- 触发：画布节点数 = 0 且无进行中任务时显示。
- 隐藏：任意对话创建即淡出（0.3s opacity + scale 1.02）。
- 首次进入可播完整动画；同一会话内反复清空只播简化版（避免打扰）。

## 七、涉及文件（实现时）
- HTML 结构：public/index.html 中央空状态容器
- 样式：新增 public/css/canvas-empty-state.css（动画 keyframes 全在此）
- 逻辑：新增 public/js/canvas-empty-tips.js（30 条词池 + 分层随机 + sessionStorage 去重 + chip 点击创建对话）
- i18n：词条补入 i18n-data.js / _union.json（如需多语言）

## 八、验收标准
- [ ] 每次清空画布/刷新后主标语与上一次不同（连续 3 次验证）
- [ ] 动画 60fps，无 layout 抖动，画布拖动性能无感知下降
- [ ] 点击 chip 能直接创建对话并带入提示词
- [ ] 创建对话后提示立即消失，不遮挡画布
