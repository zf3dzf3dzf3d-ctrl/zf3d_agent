1. ✅ 分镜文本 + 旁白稿（本版 v2）→ 等你改定
2. ⬜ 配音：旁白连贯朗读版整段生成一条音频（你有配音渠道就用渠道；没有我可以用 ComfyUI 生态里的 TTS 节点或你指定的 TTS 服务）
3. ⬜ 逐镜出图：Z-Image Turbo，16:9 电影感（cinematic, volumetric light, photorealistic, 35mm），一镜一图给你过目
4. ⬜ 图生视频：Wan2.2 i2v + lightx2v 4步加速，每镜 5 秒动态
5. ⬜ 合成：画面 + 旁白 + 字幕对轨
