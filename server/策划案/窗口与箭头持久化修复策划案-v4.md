## 〇-2、本轮新实查（收口方验证，2026-10-30）

- `public/js/user-settings.js:170-182`：beforeunload 监听已挂，`navigator.sendBeacon('/api/user-settings', {changes: pendingWrites})` 完整实现。
- 推论：**阶段 A 全部收缩完毕**——A1 已完成（服务端无罪）、A2 无必要（saveAll 无防抖吞改动问题）、A3 已存在。阶段 A 唯一残留 = C 回归硬验收（裁决①）。

**残留小缺口（C 回归时顺带覆盖，不单独立项）：**
- 箭头 saveAll 自带 300ms 防抖（app-canvas-arrows.js:50-58）：若最后一次改箭头后 <300ms 内关页，UserSettings.set 尚未调用、pendingWrites 为空，beacon 发不出。C 回归按"画完等 1 秒再重启"操作即可绕过；若实测仍丢再考虑 saveAll 立即 set（0.5h 级改动）。
