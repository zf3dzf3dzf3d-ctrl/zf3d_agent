# 使用帮助

## 安装与启动

1. 下载解压到任意文件夹（Windows 10/11 双击即用；Linux 需自备 Python 3.11+，运行 `Linux/start.sh`）。
2. 双击 `.启动朱峰社区智能体无限.bat`，完事。
3. 第一次进去按提示填 API Key 就行；嫌麻烦可以直接开个对话说「帮我连通其他模型」，AI 管家带你配完。

## 快速上手

1. 双击启动 → 浏览器自动打开本地页面。
2. 配好至少一个模型的 API Key。
3. 在画布空白处右键 → 创建对话，挑个模型开工。
4. 把任务交代清楚（要什么、做成什么样），AI 自动拆解开干；想多线并行就多开几个对话。
5. 试试这几个好玩的：
   - 输入框粘一大段文字 → 自动变成卡片
   - 按 `Tab` → 一步开新对话直接发消息
   - 对 AI 说「把方案画成流程图部署到画布」→ 真流水线跑起来
   - 对 AI 说「派出一个团队做 xx」→ AI 组队干活

## 无限画布

基本手势：
- **挪画面**：按住鼠标中键拖
- **放大缩小**：滚轮
- **双击空白**：弹出创建面板（对话/图片/视频等）
- **右键空白**：快速创建条，按上次的设置直接再开一个对话
- **Tab 键**：一步开新对话并发消息
- **小地图**：右下角缩略图，画布大了靠它找路
- **后悔药**：Ctrl+Z 撤销、Ctrl+Y 重做；图片还能点底部历史缩略图条切回任何一张
- **桌面小装饰**：顶栏有时间、农历节日、天气动画；画布标题可以钉在屏幕左边；背景能开流星特效

画布上能摆什么：

| 东西 | 干嘛用的 |
|---|---|
| 对话框 | 一个 AI 员工，核心单位 |
| 图片面板 | AI 画图和看图 |
| 视频面板 | AI 生成视频 |
| 提示词面板 | 管理和生成提示词（给 AI 的咒语） |
| 风筝节点 | 对话之间派活连线 |
| 流程图 | 流程图 / 部署成真流水线 |
| 演示节点 | 播放 AI 做的幻灯片 |
| 内置浏览器 | AI 像人一样操作网页：打开、点击、填表、截图 |

任务簿：画布上的便签不只是备忘——对 AI 说「把这个记到任务本上」，它干完会推给你验收：
- 三处联动：画布便签、AI 的任务清单、任务簿同步显示进度
- 顺口记日期：「9 月 10 号提醒我交房租」→ 自动变成日历提醒，到期弹窗+系统通知双提醒
- 过期任务自动置顶标红，当天到期高亮

## 对话框

- **每个对话独立选模型**：A 用 DeepSeek、B 用 Kimi，互不干扰
- **干活模式**：极简/编程/写作等，按对话切换（见下文「AI 怎么干活」）
- **排队机制**：AI 干活时你再发消息会自动排队，可编辑可撤回
- **粘贴自动变卡片**：粘一大段文字自动变卡片，AI 分得清你打的字和粘的内容
- **过程可折叠**：AI 干活的过程能收起来，界面清爽
- **回复好看**：代码高亮、图表渲染、选项可点
- **自动起名**：对话按内容自动命名
- **派出按钮**：对话框上一点，直达组队面板

## 项目工作台

项目工作台是每个项目的指挥室：
- **团队页**：看队员、分组、派人，AI 自动写员工档案
- **数据页**：重要数据钉成卡片，AI 额度余额一目了然

## 派出团队

像游戏组队一样派人：
- 对话框上的派出按钮 → 打开卡通小队面板
- 点一下加人、右键撤人；面板记得住你上次摆哪了
- 派完自动收起；派单时能附一句叮嘱

大活儿走专家团「4派2收」：
1. 派出前先弹确认窗：给你看这次派谁，不满意可以换
2. 策划师出方案 → 施工队动工 → 优化师+安全师同时把关（4 派）
3. 反驳师专门挑刺 → 裁决拍板收货（2 收）——活干没干好，不是 AI 自己说了算
4. 画布上箭头实时显示进度，所有人交完工才收口，不会提前散伙

新上岗的角色：

| 角色 | 干嘛的 |
|---|---|
| 验证师 | 拿多个程序交叉实测，不合格一票否决 |
| 反驳师 | 独立窗口专门挑刺 |
| 进化师 | 记录改进课题，让团队越干越强 |
| 优化师 / 安全师 | 精修文字 / 安全检查 |
| UI 设计师 | 界面类任务的专家 |

## 员工档案与团队分组

- 派出去的 AI 一键转正入职 → 自动生成员工档案
- 团队按项目分组管理
- 员工经验跨对话积累——干过的活都记得，越用越顺手

## 风筝系统

- 主对话把任务分给其他对话（像放风筝派活），自动盯进度、收结果，画布上用风筝+连线表示
- 点风筝龙头直接语音通话，像打电话一样聊
- 和派出团队怎么选？日常小活用风筝随手派，正式大活用派出团队（有人验收更放心）

## 电脑互相遥控 + 手机遥控

两台电脑互相遥控：装了本软件的两台电脑，可以像操作自己机器一样操作对方（看到一模一样的「影子界面」）。
1. 两边都开 设置 → 远程控制
2. 被控的一边生成 30 秒一次性配对码
3. 控制的一边输码 → 双方核对比对码（防坏人冒充）→ 授权生效（1 小时~30 天可选，不给永久权限）

六层安全防线：盲配对、一次性码、双向比对、限时授权、加密中转、异常自动熔断。

手机遥控：手机装个 App，出门也能派活、盯进度、看结果——数据加密、和电脑端一个账号。

## AI 怎么干活

每个对话可以选不同的「干活模式」：

| 模式 | 适合干嘛 |
|---|---|
| 极简 | 日常对话、读写文件、执行命令 |
| 编程 | 写代码开发（Git、定时任务、数据库、大计划） |
| 写作 | 写文章（润色、改写、40 个文本工具） |
| 视觉 | 识图、画图、生成视频、剪视频 |
| 流程图 | 画流程图/思维图/动画并部署 |
| 黑客 | 安全研究、网络探测类任务 |

另带内置浏览器（AI 操作网页）、视频剪辑、文档转换等专项能力。

干活保命特性：
- **失败自动重来**：任务挂了自动重启对话重试，可以挂机
- **完工专门验一轮**：做完再验证一遍，又快又省钱
- **结果一键直达**：「查看成功 N」按钮直接跳到答案

## 接入各种 AI 模型

- **不属于任何一家**：DeepSeek、千问、智谱、豆包、Kimi、GPT、Claude、Gemini、混元、文心、Ollama……只要兼容 OpenAI 接口都能接
- **AI 管家帮你配**：对话里说一句就能加模型、查模型列表
- **自动测速**：后台探测每个模型的响应速度，快的排前面，慢的靠后
- **密钥安全**：只存本地，界面上全部打码

## 超长计划（大任务不烂尾）

几十步的大任务，普通对话容易「聊一半忘了」。超长计划 = 把整个工程写成一份计划文件，AI 照单施工：

- **自动拆步骤**：AI 把目标拆成一步步，每步写清楚做什么、交什么、怎么算合格
- **一批批干**：每次只干一批（默认 5 步），防止「记忆」被撑爆；干完汇报勾选
- **中途能改**：目标变了随时修订计划，不用推倒重来
- **关机不断档**：计划存成文件，明天新开对话 AI 自动接着干
- **进度随时看**：一眼看到完成度、卡在哪

一句话：任务越大，越要先建计划再开工。你只在验收节点把关，剩下排队干完。

## 一键搬家

- 万能导入：旧版/其他 AI 工具的聊天记录直接读进来（支持 dsh / codely 格式）
- 密码库、浏览器记忆也能跨版本搬，换电脑不丢资产

## AI 画图 / 生成视频 / 动画

- **文生图**：画布上开图片面板让 AI 画；底部历史条可翻旧图，也能框选一块让 AI 局部重画
- **生成视频**：视频面板一键出片；AI 导演台更狠——一句创意 → 自动分镜 → 逐镜生成 → 拼成成片
- **AI 剪视频**：纯本地剪，不传云端——自动加字幕、找高光、去废话、文案一键成片
- **看图看片**：双击放大、可拖拽、Delete 删除（带确认）
- **动画工坊**：一句话生成矢量动画，可变速预览
- **2D 角色流水线**：一句话生成动画角色——自动画图、抠图拆件、绑骨骼，全程不用动手

## 常见问题

**Q：派出团队后箭头提前收口/少了人？**
A：已修复。还有问题就去「后台任务监控」看每个成员的状态。

**Q：派出前想换人？**
A：确认窗口那一步随便换，确认了才正式派。

**Q：科技树位置重启后又乱了？**
A：已根治。万一还有问题，一键恢复默认位置。

**Q：别的 AI 工具的聊天记录怎么搬进来？**
A：文件菜单 → 万能导入，选文件即可。注意：dsh 格式需要电脑装了 zstandard 库（没装会提示），codely 格式不用。

**Q：数据卡片关不掉？**
A：已修好关闭按钮；也可以用工作台的删除按钮移除。

**Q：我的数据安全吗？**
A：全部本地运行；密钥只存本地受保护目录；手机版加密存储。
