# ZF3D Agent Infinite (朱峰智能体无限)

**A local-first AI multi-window workbench — turn AI into a team with roles, monitoring and memory.**

v5.5.0 · Windows / Linux / macOS · Local Python service + Browser UI

</div>

## What is it

Open any number of independent AI windows on an infinite canvas. Each window has its own persona, model, engine and tools — working together on everything from chat and coding to 3D / video production.

## Highlights

- 🖼️ **Infinite Canvas** — AI windows, browser, 3D engine, video and PPT are all nodes on one endlessly pannable/zoomable canvas; click arrows to hand tasks between nodes
- 🪟 **Independent Windows** — each window has its own model, persona, UI, engine, toolset and git branch
- 🎭 **Multi-role Pipeline** — Planner breaks down tasks → Builders execute → Reviewers verify; cross-checking sharply raises success rates and saves tokens
- 🛤️ **Window Pool + Track Network** — tasks flow across a pool of windows like traffic, with resume-from-breakpoint support
- 🪁 **Kite Monitoring System** — background watchdogs auto-detect stalls and self-heal
- 🧭 **Navigation & Tidy-up** — one click to organize the canvas and locate windows
- 🎯 **Long Tasks & Memory** — persistent plans carried across conversations; semantic memory keeps project context
- 🧰 **Full Toolbox** — built-in browser, 3D engine & generation, PPT generation, image workbench, TTS, screen capture & recording

## Quick Start

1. Run `.启动朱峰智能体无限.bat` in the root directory (run `.安装依赖.bat` on first use; Linux/macOS: see the `Linux和Mac启动器` folder)
2. Open `Settings → Model Config` and fill in your API Key (or register a ZhuFeng account to use it keyless)
3. Create a window on the canvas, pick a persona, and start your first conversation

Default panel address: `http://127.0.0.1:8555` (v5.5.0)

## 二、核心功能：无限画布与多窗口


### 2.1 无限画布

- 面板就是一张可无限平移、缩放的画布，每个 AI 聊天窗口是画布上的一个节点
- 节点类型丰富：**AI 窗口节点、浏览器节点、3D 引擎节点、视频节点、演示（PPT）节点**等（对应 app-canvas-*-node 模块）
- 节点之间可以拉**箭头连线**（app-canvas-arrows），表示任务流转：比如"策划窗口 → 程序员窗口"交付需求
- **角色拖放**（role-drop）：把角色卡片直接拖到画布上即生成一个该角色的窗口

### 2.2 多窗口与窗口独立设置

每个窗口完全独立，互不干扰：

| 可独立设置 | 说明 |
|---|---|
| 模型 | 每个窗口可用不同模型/不同服务商 |
| 角色（人设/UI） | 每个窗口可绑定不同角色、系统提示词与窗口外观 |
| 工具集 | 每个窗口启用不同的工具分类：极简|编程|黑客|写作|DCC 等 |
| Git 分支 | 每个窗口可绑定独立代码分支，互不覆盖 |
| 团队人员 | 多窗口组成团队，任务在窗口间流转(策划师|质检员|多角色箭头方式协同工作) |

### 2.3 多窗口池与"赛道交通网络"

- 后台有**窗口池**（chat_pool / dispatch pool）统一调度，任务像车辆在赛道上一样在多个窗口间通行，避免单个窗口卡死拖累全局
- 池支持断点恢复（pool_resume）：服务重启后任务能接着跑

### 2.4 导航与整理

- 画布支持**导航/整理**功能：一键整理杂乱窗口、快速定位某个窗口，多窗口管理一目了然
- 窗口锁（canvas-node-modal-lock）撤销重做保存读取可防止误关正在干活的窗口

## 三、AI 能力工具箱

所有工具由 AI 自主调用，你只需用自然语言下指令。通过策划师和质检员的多轮对话,可以显著提高任务成功率。

### 3.1 文件与代码

- 读写文件、目录树、全局搜索、精确替换、移动文件（read_file / write_file / search_in_files 等）
- **前后保存git**：所有对话会在初始和结尾分别保存一个 git，保证工作永远不丢。
- **修改和删除**：修改文件之前必做备份，删除之前先移动到垃圾箱；超级大文件或者多文件删除必然先向用户提问。

### 3.2 3D 与美术

- **model_3d_gen**：文生 3D / 图生 3D（tripo、meshy、rodin、hunyuan 四家服务商），生成结果自动加载进内置 3D 工作台预览
- **zf3d 引擎节点**：画布上的 3D 引擎窗口（内置骨骼等工具为未来开发游戏打好基础,大模型驱动,超轻量）。

### 3.3 图片、视频、语音

- **image_gen** 文生图、**video_gen** 文生视频、**video_edit** 视频剪辑
- **TTS 语音合成**（tts_engine）：AI 朗读回复，支持流式输出
- **语音输入**（audio_recorder）：按住说话转文字

### 3.4 内置浏览器与自动化

- **browser_control**：AI 打开网页、点击、填表、截图、读正文、执行 JS，登录态跨重启保留
- 浏览器节点可直接钉在画布上当窗口用

### 3.5 屏幕与桌面

- **屏幕截图**（screenshot_capture / area_selector 区域选择）
- **屏幕录制**（screen_recorder，含转码）
- **键鼠控制**（set_camera / locate_mouse / control_keyboard）

### 3.6 其他

- **网页搜索 / 网络诊断**（net / net_ping / http_probe 等网络工具箱）
- **send_email** 发邮件
- **表格查看器 / pdf / word / PPT 技能**：内置 PPT 查看器，这是一套大模型直接操作的轻量生成能力，无需外挂二进制文件。

## 四、高级功能：多角色协作与风筝系统

### 4.1 策划师 / 质检员 / 施工队 / 总结师 / 多角色一键创建与一键返回

- 一键创建**多角色流水线**：策划师先拆解任务 → 执行者实施 → 质检员验收,一键多轮验证，大幅提高任务成功率和扩展性
- 对应模块：dispatch_swarm（蜂群调度）一个对话内部并发多子任务,可和主对话同时执行.不耽误开发时间.

### 4.2 施工队与 Git 赛马（多路开工/分工/回收）

- **多路开工**：结果增强按钮行点「施工队」→ 选数量 → 每队自动建一个**物理隔离施工场地**（git worktree，独立目录+独立分支 `site/race/<时间戳>_tN`），互不干扰可并行。
- **开工机制**：建场后自动开施工队角色窗，并把「开工派单消息」自动注入发送；若注入失败会弹 toast 提醒手动粘贴。源对话与施工队窗之间有橙色连线标识派单关系。
- **如何分工**：派单带计划 planId 时，施工队用 long_plan 读取计划 → plan_batch.claim 认领一批步骤执行，只做计划内步骤；多队并行即形成"赛马"，谁先做好用谁的。
- **如何回收**：各队成果落在各自分支上，比选后把优胜分支合并回 main，其余场地（worktree）可清理移除。清理前务必确认无未合并改动。

### 4.3 风筝系统（监控一切）

- **风筝查看系统** 观察每个对话,观察每条赛道,监控系统稳定性,窗口绘制情况,卡顿情况.
- **FPS 守卫**（mixin_fps_guard）：界面卡顿自动降载
- **网络守卫**（network_guard）：断网/代理异常自动重试
- **索引守卫**（index_guard）：主脑或小狗守卫等多种守卫方式，各管一摊，出问题自动拉起对话。

### 4.4 长任务与长期记忆

- **长任务 + 超长任务+长期目标**：超长任务落成持久化 MD 计划，跨对话接力执行，分批认领防上下文爆炸,超长任务模式所有工具结果全部保留,一字不丢.长期目标,可以设置跨对话的长期目标,可随时监控只要未完成就持续完成.
- **任务清单 task_list**：面板实时展示进度
- **长期记忆|工具记忆|项目记忆|内存记忆|目标总结记忆**适应短期中期长期任务,无感运行,一键记忆.
- **通信**：具有窗口通信监控调取工具结果的能力.

### 4.5 模式系统（modes/）

- 内置模式：对话引擎可以热插拔,可随时集成任何智能体引擎.设置工具和上下文循环内容.每个窗口都可以设置.
- 模式 = 角色设定 + 工具白名单 + 开场白，一键给窗口换"人格"不同角色分组还可以参与多角色对话能力.

## 六、常见问题 FAQ

**Q1：如何启动？**
双击启动朱峰智能体无限.bat即可无需安装.

**Q2：AI 回复报 API Key 错误？**
检查「设置 → 模型配置」中 Key 是否有效、点击验证看连通性,如果没有apikey可以注册朱峰会员,赠送token。

**Q3：TTS 没有声音？**
界面最上面有声音按钮打开即可。

**Q4：3D 模型生成失败？**
- 现象：调用 model_3d_gen 报错或无结果
- 原因：对应服务商（tripo/meshy/rodin/hunyuan）未配置 API Key，或选错了生成类型
- 步骤：进「设置」确认已配置对应服务商的 Key；确认对话工具分类包含 3D 能力；再试一次

**Q5：在线升级失败？**
- 现象：`.在线升级.bat` 报错或升级后异常
- 原因：权限不足或文件被占用
- 步骤：关闭所有窗口后以管理员身份运行；仍失败用「备份恢复」回到旧版本

**Q6：窗口卡死不动？**
- 现象：某个窗口长时间无响应
- 原因：多为网络中断或该任务卡住
- 步骤：关闭该窗口重启即可；网络不通时重新运行启动脚本，其余窗口不用关，任务可继续跑

**Q7：想彻底重置？**
- 现象：想恢复出厂状态
- 原因/步骤：备份 `data/` 和 `private/` 目录后删除，重启即全新状态。**注意：这是不可逆操作，务必先备份。**

**Q8：画布太乱找不到窗口？**
- 现象：窗口太多摆放杂乱
- 步骤：使用画布「整理」按钮一键排版，或用导航面板快速跳转定位。

**Q9：有哪些快捷键？**
画布与窗口常用操作（拖拽移动、滚轮缩放、框选多选、连线交付）在画布上直接操作；具体快捷键以后续版本面板内提示为准，暂无全局快捷键表。

**Q10：换电脑/迁移怎么办？**
- 步骤：拷贝整个项目目录到新电脑（重点保留 `data/` 与 `private/`），新电脑先跑 `.安装依赖.bat`，再启动即可，对话记录与记忆随目录走。

**Q11：多角色流水线怎么用？**
- 步骤：见第四节 4.1——一键创建多角色（策划师拆解 → 执行者实施 → 质检员验收），在窗口设置中把多个窗口组成团队并用箭头连线定义流转顺序即可。

**Q12：Token 用了多少/用完了？**
- 查用量：「设置 → 令牌用量统计」（token_usage_stats）一目了然
- 用完了：注册/充值朱峰大模型账号，或换成自己配置的其他渠道模型

## 二、各阶段详细说明

### 5.5.0（当前版本）—— 桌面客户端与跨平台
- **独立桌面客户端**：托盘常驻，「打开主界面」打开 pywebview 原生窗口（WebView2 内核，Win10/11 零依赖），关窗口不影响后台服务，单实例复用窗口，品牌图标。
- **跨平台启动**：新增 start.sh 与 platform_compat 兼容层，Linux/macOS 可启动（解释器自动探测 .venv/自带 Python/系统 Python）。
- **大师集群**：对话框右上角大师入口统一收敛到大师集群菜单，移除各大师独立注入图标。
- **稳定性修复**：ai_accounts 余额设置改为动态探测表列，错误不再静默吞噬；token_logs 流水写入失败不影响到账响应。

### 5.4.5 —— 多角色协作与全面工具化
- **多角色协作与质检**：策划拆解 → 执行 → 质检验收流水线，一键返回重来、轮次可见，大幅提高任务成功率，无需人工反复校验。
- **多策划 / 多审核 / 多施工队**：每种角色均可开多个窗口并行工作——多份策划方案先整合对比再由用户裁决开工；施工队可多队分片同时施工；审核支持多轮多窗口复核，主窗口负责方案整合与任务派发。
- **多窗口池 + 赛道交通网络**：窗口池统一调度，任务像赛道车流通行，支持断点恢复。
- **风筝系统监控一切**：看门狗、FPS 守卫、网络守卫、索引守卫等多种「小狗守卫」，卡死自动拉回、故障自修复。
- **导航与整理**：一键整理画布、快速定位窗口。
- **长任务与长期记忆**：超长任务持久化计划跨对话接力，语义记忆记住项目背景。
- **全家桶工具**：内置浏览器、3D 引擎与 3D 生成、PPT 生成、图片工具工作台、TTS 语音、屏幕截图录制。
- 功能全景：无限画布多窗口 / 多角色流水线与工单系统（多策划·多施工队·多审核）/ 窗口池与计划分批 / 风筝监控 / AI 工具全家桶 / 技能与扩展市场 / 模型多渠道与备份恢复。

### 5.3.0 / 5.3.5（2026-09）—— 发布工程沉淀
- 延续 5.2.5 核心架构：对话池、闸门 v4、蜂群并发、小狗守卫、热更新。
- 对话与调度稳定性核心持续打磨，目录级版本快照保证发布可回溯。

核心理念：把控制权下放到每一个对话。
