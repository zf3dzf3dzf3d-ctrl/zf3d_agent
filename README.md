## 🚀 快速开始

> 不需要 `pip install`，不需要任何环境配置，下载后直接运行。

**Windows：**
下载 release 包，解压后运行 `启动.bat`

**Linux：**
下载 release 包，解压后运行 `bash install.sh`

浏览器打开 http://localhost:8765 ，在设置页面填入你的API Key即可。

> 支持 DeepSeek / 豆包 / 智谱 / Kimi / Claude / Gemini / 通义千问 / OpenAI 等10+模型，纯HTTP直连，不绑定SDK。

## ✨ 核心亮点

### 🔀 节点工作流 — 多AI协作可视化编排

拖拽连线，让多个数字员工像流水线一样协作完成任务：

- 大白话描述需求，AI自动创建节点、分配员工、连线布局
- 连线支持单次执行、固定循环、条件循环（AI判断跳出）
- 图片/文本拖入画布即创建输入节点，数据自动流转
- 节点状态实时变色，连线小球动画，双击查看输入输出
- 撤销重做、剪刀模式（Y键切断连线）、分组框、8方向缩放

### ⏰ 日历计划任务 — 按时间自动调度工作流

不用守在电脑前，到点自动执行：

- 月历视图点击日期选时间，5种重复模式（仅一次/每日/每周/每月/间隔循环）
- 前端在线：浏览器弹窗+提示音；前端离线：Windows桌面弹窗置顶通知
- ▶立即执行 / ✏️修改 / ⏸️暂停 / 🗑️删除

### 👥 数字员工 — 每个员工都是独立人格

- 专属提示词、角色、目标，AI自动生成人设
- 独立记忆库，互不干扰，越用越懂你
- 高级员工可启用文件操作、代码执行、图片生成等实操能力
- 层级管理、颜色分类、独立对话窗口、定时提醒

### 🎮 3D软件整合 — 说句话就能建模

| 软件 | 接入方式 | 操作数 | 能做什么 |
|------|---------|--------|----------|
| **3ds Max** | MCP | 117 | 说"连接3dmax"自动安装，创建物体/材质/修改器/动画/渲染/tyFlow |
| **Houdini** | Bridge插件 | 10 | 创建/删除/连接节点、VEX、Python、查询网络 |
| **Blender** | TCP Socket | 8 | 场景/物体信息、执行代码、PolyHaven资产搜索下载 |

三个软件互斥锁定，不会互相打架，按需连接。

### 🛡️ 绕路师 — AI会从失败中学习

任务失败时自动分析原因，LLM提炼绕路方案存入SQLite。下次同类任务自动注入"避坑指南"，AI不再踩同样的坑。高频失败自动写入Bug库。**聊得越多越聪明。**

### 🎨 PS级图片加工 + AI生图/视频

- 独立图片编辑器：图层系统、11种工具、选区布尔运算、滚轮缩放
- ComfyUI集成14种操作：文生图/图生图/文生视频/图生视频/prompt反推
- 云端出图：免ComfyUI直接调API，支持AgnesAI(免费)/Seedream/Nano Banana/Grok/GPT Image

## 💬 对话能力

### 🧠 神经元对话系统 — 会思考、会记忆、会反思

全新的神经元架构对话引擎，16个神经元分工协作，让AI像一个真正的大脑一样工作：

- **16神经元架构**：听觉→记忆→意图→规划→思考→模型→解析→验证→表达，每个神经元各司其职
- **流式思考可视化**：实时显示🧠思考中→🔧工具调用→📥观察→🗣️输出全流程，ReAct节点图蛇形布局
- **三层记忆系统**：
  - 上下文记忆：30条历史智能压缩，摘要保留路径/版本/配置等关键信息
  - 项目记忆：工作目录下自动维护.ai记忆.md文件，打开项目即恢复上下文
  - 关键信息提取：自动用正则提取路径/版本号/GPU/ComfyUI路径写入SQLite，永不遗忘
- **任务跟踪**：AI做了什么、哪些完成、哪些待办，用户确认✅已完成/⏳待确认/🗑️放弃
- **三种执行模式**：自动编辑（优化/修改/修复）/编辑前询问（删除/覆盖）/计划模式（分析/方案），关键词自动判断
- **经验师+绕路师**：成功自动提炼经验复用，失败自动记录教训绕开，聊得越多越聪明
- **SSE心跳保活**：长对话不断连，流式输出不卡顿
- **AI选项按钮**：AI回复中的选项列表自动渲染为可点击按钮

### 经典对话能力

- ReAct推理引擎（思考→行动→观察→校验循环），流式输出
- 闲聊 / 任务执行 / 批量任务 / 框选编辑，4种意图自动识别
- 商量 / 执行 / 无人值守 / 规划，4种工作模式
- 框选文本直接让AI改写，自动区分Word/Excel/纯文本
- Ctrl+~ 全局轮盘：选中文本随时翻译/问答/朗读/截图
