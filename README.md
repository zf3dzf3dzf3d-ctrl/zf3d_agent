# 朱峰社区智能体无限

朱峰社区智能体无限是一款面向本地使用的智能体工作台，支持在无限画布中组织对话、任务和工作内容。

## 使用方式

1. 下载或解压本项目到本地目录。
2. 双击目录中的启动脚本启动程序。
3. 按程序界面提示完成配置后即可使用。

## 目录说明

- `server/`：应用服务端程序及相关资源。
- `python/`：发布包内置的 Python 运行环境。
- `private/`：程序运行所需的私有模块和配置资源。

## 版本

当前版本：见 `private/version.json`

本仓库为 Windows 发布目录。请保持目录结构完整，不要单独移动或删除内置运行环境及服务端文件。

## 注意事项

- 首次运行前，请确认程序目录具有读写权限。
- 使用过程中产生的运行日志和本地数据属于当前设备内容，请根据需要备份。
- 发布压缩包不纳入 Git 版本管理，发布时请使用本地生成的 ZIP 文件。

## 新版本新增功能（5.0.1）

### 工具循环智能体（模式2）
- 新增会使用工具的执行型智能体：理解意图 → 规划步骤 → 调用工具 → 验证结果 → 完成任务
- 全部任务自动生成可视化任务清单，界面右侧实时展示进度

### 三大工具分类（共 84 个工具）
- **极简分类（16 个）**：文件读写、Shell 执行、目录树、全局搜索、项目记录、工单清单等基础能力
- **编程分类（27 个）**：对话数据库、长期记忆、定时任务、监控队列、Git 保存、代码大纲、AI 文生图 / 视频生成 / 邮件发送等
- **写作分类（40 个）**：改写润色、摘要提取、情感分析、SEO 优化、多角色评审（专家 / 反方 / 新手视角）、快速成文等

### 智能上下文与记忆
- **长期记忆**：跨对话保存用户偏好与配置
- **内存缓存**：临时数据中转，重启自动清理
- **工具结果存档**：超长输出自动截断存档，可随时按 ID 找回原文

### 本地数据持久化
- 内置 SQLite 数据库（zf3d_canvas.db），画布节点、视图、会话历史、任务统计全本地存储
- 支持数据库压缩维护

### 发布包优化
- 清理全部缓存、备份残留，保持发布目录干净
- 完整离线运行：内置 Python 运行环境，开箱即用
