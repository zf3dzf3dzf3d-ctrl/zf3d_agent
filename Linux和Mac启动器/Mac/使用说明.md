# Mac 版使用说明

## 📁 本文件夹文件

| 文件 | 作用 |
|---|---|
| 朱峰社区智能体无限Mac版本首次使用必点.command | 第一次用：给脚本加执行权限（只需一次） |
| 朱峰社区智能体无限Mac版本启动.command | 启动服务（窗口保持打开，Ctrl+C 停止） |
| 朱峰社区智能体无限Mac版本后台启动.command | 后台启动（可关窗口，服务继续跑） |
| 朱峰社区智能体无限Mac版本停止.command | 停止后台服务 |
| 朱峰社区智能体无限Mac版本重启.command | 重启服务（改了代码后用） |

## 🚀 三步上手

1. **安装 Python**（只需一次）
   终端运行：`brew install python3`
   （没有 brew 就去 https://www.python.org/downloads/ 下载安装）

2. **双击「朱峰社区智能体无限Mac版本首次使用必点.command」**
   - 若 Mac 提示"无法验证开发者"：右键文件 → 打开 → 再点"打开"
   - 或者：系统设置 → 隐私与安全性 → 仍要打开

3. **双击「朱峰社区智能体无限Mac版本启动.command」**
   - 首次会自动安装依赖（需要几分钟）
   - 完成后浏览器打开 http://127.0.0.1:5000

## 🔐 权限授权（按需）

在 系统设置 → 隐私与安全性 中，给终端（或打包后的 App）勾选：
- **辅助功能** — 全局热键 Cmd+` 呼出、鼠标控制
- **屏幕录制** — 截图/录屏功能

## 📦 想要真正的 App？

终端运行 `scripts/macos/build_app.sh`，会生成 `dist/朱峰社区智能体无限.app`，
拖进「应用程序」文件夹，像普通 Mac 软件一样点击图标启动。

## ❓ 常见问题

- **双击弹出"无法执行"** → 先运行「朱峰社区智能体无限Mac版本首次使用必点.command」
- **端口被占用** → 双击「朱峰社区智能体无限Mac版本重启.command」
- **看日志** → 项目根目录的 `server.log`（后台模式）
